## その週に存在した王

- 対象115Rの3連単払戻に、10,000円以上は29件。
- 最大は175,630円。
- 中央値は4,400円。
- 盤面生成できた114Rでは王捕捉0。
- 未生成1Rを最悪ケースとして差し引いても、少なくとも28件の王機会が存在したのに0捕捉。

## 解釈

参加判定だけが王を捨てたわけではない。
参加・見送りを無視して全盤面を買っても王は0だったため、問題は盤面候補形成そのものにある。
現行方式は低〜中配当の捕捉へ寄り、高配当の右裾を体系的に切っている可能性が強い。
