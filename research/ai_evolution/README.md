# 競輪AI進化研究所 — GEN-001

## 第1世代（2026-10-19）

既存の市場残差確率モデルを不変の第1世代として採用。**新規に学習したモデルではない**。モデルと監査レポートを元の Git blob SHA のまま保存し、可視化用の世代レジストリを公開する。

### 何が動くか

- 45係数のチェックポイント：generations/g001/model.json
- 出典監査全文：generations/g001/audit.json
- 世代仕様：generations/g001/manifest.json
- 事前T-15実測スナップショットの厳格な紙上推論：predict.py
- 全3連単組番に対する補正確率の計算、推定期待値が閾値以上の**全候補**を出力（4点制限を付けない）
- 事後・確定オッズのT-15偽装、結果の特徴量混入は既存T-15バリデータが拒否する
- GitHub Pages の /ai-lab/ で世代系譜、精度比較、収支評価、係数を可視化

### 第1世代の既存評価

2023〜2025年のS級（5〜7車）を学習し、2026年上半期の2,523レースを評価した既存成果を採用。市場Log Loss 4.1903095 → 補正 4.1789522。Brier 0.9640495 → 0.9634259。市場のみより確率スコアは改善。

過去の確定オッズを使った「最高推定EVの3連単1点、推定EVが1.10以上」の仮想選択は378レース・3的中・92.41%回収。事前に購入できたという意味では**ない**。2026上半期は時系列上の後期間だが研究で既に使われており、完全未見の検証ではない。厳格に認証済みのT-15前向き検証は **0レース**。プラス収益はまだ実証できていない。

### 進化の永続規則

1. 過去世代のモデル・出典監査・評価記録は変更しない。
2. 次世代ごとに別ディレクトリ・別バージョン・別モデルを保存する。
3. 学習に使った期間を検証に再利用しない。過去に探索で使用した期間は未使用扱いにしない。
4. 親世代、市場、単純な市場温度補正との同条件比較を必須にする。
5. 的中率だけでなくLog Loss、Brier、較正誤差、実際に執行可能な払戻と収支を区別する。
6. 特定の券種・点数・フォーメーションを本来の研究目的として固定しない。GEN-001の3連単限定は**初代の実装制約**であり、最終研究の制約ではない。
7. 第2世代以降のAI自動生成・競争・淘汰システムは別工程で作る。現リリースは自律進化の稼働を主張しない。
