# ハルキュー V6-C1：2023年 第1週（1月1〜7日）

## 研究手順
観察 → 問い → 仮説 → 検証 → 結論 → 保存。第1週の結果から後付けで黒字条件を選ばない。次週へ進む際は同じ候補モデル・ルールを固定したまま別週で検証する。モデル自体の再学習や、表／裏ハルキューへの組み込みは禁止。

## 1. 第1週で判明したデータの構造的バグ

- 全7券種暗号化オッズ原本：**552レース／7日**。
- 誤って保存されていた3連単組番の**2着と3着が逆**になっていた。原本は変更せず読み込み時だけ補正。
- 公開用3連単との共通327レース、**74,034組番の価格が補正後100%一致**。
- 公式払戻が確認できる367レース、**367／367レース一致**。修正前は0／367。
- オッズを「市場の大間違い」とみなした過去の研究結果は、この組番バグの影響を強く受けているため再評価が必要。

「確定オッズによる払戻換算」は公式払戻を直接確認できない当たり（V6で3件、V6-C1で4件）も含む。**公式払戻そのものと混同しない**こと。独立ソースで確認した全367件は完全一致しており、組番価格補正が正しいことは第1週について証明された。

## 4. 結論と第2週への引継ぎ

1. 市場価格の巨大誤差に見えた現象の一部は**2・3着転置のデータバグ**。これを全週・全年に無検証で一般化せず、各週の払戻照合で必ず再点検。
2. 正しい価格での第1週はすべての方式が赤字。買い目選別は損失率を改善したが、**市場優位性が証明されたわけではない**。
3. まだ同じ第1週を材料として価格誤差条件・モデル係数・フォーメーション閾値を最適化しない。
4. 次週は**2023年1月8〜14日**。同じデータ照合、同じV6・V6-C1、同じ購入判定、同じ投資法を使って観察する。
5. この試験はV6/V6-C1双方にとって2023年1月を含む学習期間の再生であり、未知期間での利益保証ではない。オッズは事後取得の確定価格であり、締切前購入可能だったことを意味しない。
