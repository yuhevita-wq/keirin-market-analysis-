# ライン着順結合分析

**着順のどの組が同じラインで結び付くかを、級・車数・ライン構成別に測る分析。**

英語識別名：`line_finish_linkage`。2026年10月14日に命名・保存。

## 定義

- **12結合**：1・2着が同じライン。
- **23結合**：2・3着が同じライン。
- **13結合**：1・3着が同じライン。

表裏とライン内の非隣接ペアを含む。単騎同士は別ライン。ラインは掲載予想並びに基づき、実走中の切替・追走を観測したものではない。人数順に構成を正規化し、3−1−3は3−3−1に含める。

## 主要結果：7車立て

A級は1・2班。比較表は確定1・2・3着が一意の同じレース集合で計算。

|級・構成|対象R|12結合|23結合|13結合|
|---|---:|---:|---:|---:|
|A級・全体|39,664|57.5%|36.6%|37.3%|
|S級・全体|16,185|54.6%|32.3%|33.7%|
|A級・3−2−2|18,648|56.8%|32.8%|33.7%|
|S級・3−2−2|9,037|56.6%|32.1%|33.8%|
|A級・3−3−1|7,539|63.3%|46.8%|47.4%|
|S級・3−3−1|2,219|61.2%|43.7%|46.1%|
|A級・2−2−2−1|4,083|42.0%|15.1%|15.9%|
|S級・2−2−2−1|2,137|43.5%|13.6%|14.4%|

主要3構成では12結合が多く、23結合・13結合は近い頻度。3−2−2に絞ると級間差は小さい。

13結合には「3人全員同ライン」と「1・3着同ラインで2着別ライン」の両方が含まれる。3−2−2では後者がA級16.19%、S級16.69%（全対象Rを分母）。これをクロス4点の的中率と混同しない。

## データと制約

対象期間は2023年1月1日〜2026年6月30日。元データ：このリポジトリのコミット `91713712edc4c5c21c20d8aea66d999cbb0de1f4`。

A級1・2班、A級チャレンジ、S級および車数を分離。S級はF1・予選補助・G1/G2/G3収録分。全国全開催の網羅データではない。S級F1の2023年1〜3月は全種別results.csvがなく、予選補助等で取得できた分のみ。チャレンジの2023年初期にも欠損区間がある。

同じrace_idは1回のみ。掲載並び欠損・競り等の複雑表記、対象着順の同着・欠損、結果未取得を除外。事故等は対象着順が一意なら本集計に含め、除外する補助集計も保存。

12単独集計では3着を要求しないため、A級39,752R・S級16,225Rが対象。23・13および3組の比較とは分母が少し違う。

数字は収録レースの観測頻度。特定選手ペアの確率・将来の確率保証・利益・クロス4点の的中率ではない。オッズ・払戻は今回使用していない。

## 保存内容

- [12結合レポート](pair12/report.md)：全構成・全車数・級別・年度別・補助集計。
- [23結合レポート](pair23/report.md)：2・3着の同ライン／別ラインと12結合との比較。
- [13結合レポート](pair13/report.md)：1・3着の同ライン／別ライン、3組比較、内訳。
- 各フォルダの `summary.json`：件数、割合、Wilson 95%区間、欠損理由、元データ一覧。
- `pair23/comparison.json`、`pair13/comparison.json`：同一レース集合での比較。
- [全ペアのレース別判定](race_details_all_pairs.zip)：83,917RのJSONL。掲載並び・1〜3着・same12/same23/same13・元データパス等。
- `analyze_pair12.py`、`analyze_pair23.py`、`analyze_pair13.py`：元CSV／ZIPから再集計するコード。
- `validate_saved_results.py`：保存済みの全判定・構成別件数を別処理で確認。

レース別判定のnullは、そのペアを判定できず集計から除外したことを示す。12のみ判定できる204Rを含む。

## 再実行

Python 3、pandasを使用。リポジトリのルートで実行する。

```bash
python3 research/line_finish_linkage/analyze_pair12.py
python3 research/line_finish_linkage/analyze_pair23.py
python3 research/line_finish_linkage/analyze_pair13.py
python3 research/line_finish_linkage/validate_saved_results.py
```

分析スクリプトは各pairフォルダに集計JSONと個別JSONLを出力する。保存時の再現には上記固定コミットのデータを使用する。データが更新された状態での再実行結果とは区別する。
