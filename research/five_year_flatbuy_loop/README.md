# 過去5年の全保存レース平買い → 100%超の特徴 → 見送り選別 → 反復

既存ハルキューの印・買い目・推奨・閾値とは独立した研究実装です。
「予想の的中率」ではなく「同条件に該当する全組番を過去全レースで100円ずつ平買いしたらプラスか」から開始します。

## データ母集団

- 発見期間：2021-01-01～2025-12-31（アーカイブに保存されたレースのみ）。
- 未知検証：2026年上半期（この結果で過去の採用条件を選ばない）。
- オッズ：data/odds_only/odds_YYYY.jsonl.gz（3連単・3連複の全組番）。
- 結果：data/results_only/results_YYYY.jsonl.gz（厳密な race_id 対応の検証済み入着）。
- 女子・結果欠損・オッズ欠損・不完全な組番表・異常IDは除外し、その件数を監査で表示。ゼロ払い扱いしない。
- **全国の全レースが揃っているわけではない。** 2021年と2022年の保存率は特に低い。
- 2021～2025年の同一仕様の選手・ライン情報は未統合であり、現段階の特徴は車立て・レース種別・開催格・オッズ帯・人気帯・1着候補の市場支持順位など。選手条件を発見したことにはしない。
- ワイド・2車単・2車複等はこのオッズアーカイブに収録されていないため本コードでは未検証。

参考監査: data/audits/odds_only_export.json、data/audits/results_to_odds_alignment.json

## 処理

1. すべての保存済み完全オッズ表を開き、3連単・3連複の全組番を「それぞれ毎回100円買う」と仮定し、的中・払戻・ROIを集計する。
2. 事前に定めた単独特徴の平買いを網羅的に実施する。100%超で件数・的中数・複数年安定性を満たした条件を報告する。
3. その条件と一致しない車券は見送り、残りに対して別の特徴をAND追加して、再び全件平買いする。
4. ROIが上がらないか、新条件が見つからなくなれば停止。デフォルト最大3段階。
5. 未来混入防止の時系列検証：2021～22年で学習→2023年テスト、2021～23年→2024年、2021～24年→2025年、2021～25年→2026年上半期。
6. それぞれの未知年には、その直前に固定したルールに合致した全組番だけ買い、購入数と未購入レース数、損益を保存する。

2021～2025年の全体でROI100％超を発見したことと、未知期間でもプラスだったことは区別する。
全期間の事後的なランキングを過去年に適用して「的中」とはしない。

## 実行方法（リポジトリ直下）

    python -m unittest discover -s research/five_year_flatbuy_loop -p 'test_*.py' -v

    python research/five_year_flatbuy_loop/run.py --first-year 2021 --last-year 2025 --holdout-year 2026 --depth 3 --min-bets 500 --min-hits 10 --min-profitable-years 2 --min-gain 0.02

既存の data は読み取り専用、出力は results/five_year_flatbuy_loop のみ。

| 出力 | 中身 |
| ---- | ---- |
| flat_buy_profitable_conditions.csv | 全5年で100％超の単独特徴を小標本も含め全件列挙。購入候補適格フラグと年別ROIを別列で表示 |
| report.json | 全件平買い基準、データ監査、各ステップの候補・採択・却下、年別成績 |
| walk_forward.csv | 凍結条件での年別購入レース数・購入点数・投資・払戻・利益・回収率 |
| decisions/frozen_YYYY.csv.gz | 各未知年に買った全組番・価格・的中・払戻近似・採用ルール |

GitHub Actions: .github/workflows/five-year-flatbuy-loop.yml
PRでテスト、全アーカイブの計算はGitHub Actionsの「Run workflow」で手動実行し、
その実行に紐付くartifactへ成果を保存する。

## 厳格な留保事項

- 払戻額は「勝ち組番の確定オッズ × 100円」で近似。正式払戻や返還と照合していない。
- 記録は確定オッズであり、実際の締切時点で同価格が購入可能だったとは証明できない。
- 高配当少数件・多条件探索・欠損率の偏りで開発期間のROIは過大評価され得る。
- 同レースで条件を満たす組番が複数なら、全点を100円ずつ買う。金額=点数×100円。
- 最初から印・1着固定・既存フォーメーション・合成オッズ閾値に依存しない。
- 選手・ライン・展開の特徴も分析する段階には、5年間で同じ仕様のレース前
  出走表を race_id で接合し、情報欠損による選択バイアスを検査する必要がある。
