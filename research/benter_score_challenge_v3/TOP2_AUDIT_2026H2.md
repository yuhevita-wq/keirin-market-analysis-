# 1着候補2人制のモデル比較 — 2026下期

## 目的
1着予測を各レース**1人→2人**に広げる場合、競走得点上位2人より高確率で勝者を含められるか。

## データ・手順
- 2026年7月2日〜8月30日F1・S級。予測済み875レース中、勝者が複数いるなど従来と同じ基準で3レース除外し、**同一872レース**で比較。
- 研究時にGitHubにコミット済みの `frozen_2026h2_probabilities.csv` をそのまま用い、**再学習なし・車番上位2人のみ**を選択。順位同点時は車番昇順。
- 比較対象は各レースの競走得点上位2人。同じ2人枠なので、1人を選ぶベースラインとの不公平な比較を避けた。
- 正解: 実際の1着選手が選んだ2人のどちらかに入っている。2着と3着は無関係。

## 結果

| 方式 | 的中 | 率 | 得点上位2人との比較 |
| --- | ---: | ---: | ---: |
| 競走得点上位2人 | 493 / 872 | 56.54% | 基準 |
| 得点のみ多項ロジット上位2人 | 493 / 872 | 56.54% | ±0 |
| V2（ライン相互作用ロジット）の上位2人 | 523 / 872 | 59.98% | +30R / +3.44pt |
| V3（選手+ライン非線形）上位2人 | **539 / 872** | **61.81%** | **+46R / +5.28pt** |
| V3（得点を使わない非線形）上位2人 | 484 / 872 | 55.50% | −9R |

得点上位2人 vs V3: 両方的中432R、V3だけ的中107R、得点だけ的中61R、両方外れ272R。
得点上位2人 vs V2: 両方的中415R、V2だけ的中108R、得点だけ的中78R、両方外れ271R。

## 日付単位での再標本化
59日分を日付単位で5,000回復元抽出して、同日の複数レースが相関することを一定程度考慮。
- V2−得点2人: +3.44pt、95%区間 **+0.45〜+6.36pt**
- V3−得点2人: +5.28pt、95%区間 **+2.21〜+8.29pt**
- V3−V2: +1.83pt、95%区間 **−0.39〜+4.10pt**。両モデル間の優劣は確定しない。

## 結論・制約
- **同じ2人枠の比較で、どちらの独自モデルも競走得点上位2人を超えた。**
- V3は1人選択でV2に負けたが、2人選択ではV3の的中率が高かった。最適化目的を変更すると最良モデルが変わりうる。
- **ただし、V3を最良とする選択はこの期間のテスト結果を見た後の探索的選定である。** 独立した次期間で2人選択を目的に固定して再確認するまで優位性の確証としない。
- データはレース別の過去出走表で、取得日が後というだけで現在プロフィールの混入を示すものではない（既存訂正記録参照）。
- 2人に1着が入る確率が高いことは、単勝2点を買って期待値プラスであることと同義ではない。購入はオッズとの統合後に評価。
- 2人選択の的中率改善は認められるが、**ビル・ベンター方式の独立予測＋市場確率の統合の完成ではない**。
