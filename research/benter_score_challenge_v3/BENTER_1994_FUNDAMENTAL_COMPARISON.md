# ビル・ベンター（1994）本人の独自モデルと、競輪独自モデルの同一定義での比較

## 同じ数式で計算する

ベンター原論文 (1994) p.189, Eq.(3):

```text
pseudo-R² = 1 - L(model) / L(1/N_j)
L(model)   = -sum_over_races log(P(predicted winning rider))
L(1/N_j)   = sum_over_races log(number of starters in race)
```

出典: https://gwern.net/doc/statistics/decision/1994-benter.pdf

ベンターの香港競馬3,198レース、32,877頭の標本に対する値:

- 独自 fundamental model 0.1245
- public betting 0.1218
- combined model 0.1396

ここで比較対象にするのは**独自 fundamental model 0.1245だけ**。車券オッズとの統合はしていない。

## 競輪の計算対象

出走前の各レースに紐づく過去選手データのみで生成された、すでにコミット済みの独自モデル予測確率 `frozen_2026h2_probabilities.csv` を使用。

- 2026年7月2日～8月30日
- F1 S級、1着が一意な872レース
- 選手出走数6,025、平均6.91人（5車8R、6車63R、7車801R）
- 結果: `individual_results.csv` に事前固定された予測と突合済み
- 該当期間を学習用ラベルにしていない。検証後の再学習なし。

| 予測法 | log loss | uniform log loss | Benter Eq.(3) R² |
|---|---:|---:|---:|
| 競走得点のみ | 1.682228 | 1.931686 | 0.129140 |
| 独自モデル2（ライン相互作用） | 1.577816 | 1.931686 | **0.183192** |
| 独自モデル3（非線形） | 1.577753 | 1.931686 | **0.183225** |
| 競走得点除外の非線形 | 1.691828 | 1.931686 | 0.124170 |

独自モデル2の疑似R²は、同一式で計算した数値として、ベンターの `0.1245` より約0.0587高い。ただし競技が違うため、この数字をもって「ベンター以上」と**ランク付けできない**。そもそも競走得点単独でも0.1291となり、ベンターの発表値を少し上回る。したがって重要なのは競輪内の得点単独との相対比較（モデル2改善 +0.05405）である。

## ベンター本人が重視した予測確率の校正

原論文 p.186 Table 2 (本人の fundamental model):

- 予測40%以上の324頭: 平均予測47.5%、実際43.2%、誤差 -4.3ポイント。

当方モデル2の2026年下期・同じ予測40%以上の363選手:

- 平均予測 **53.73%**
- 実際の1着率 **45.45%**
- 誤差 **-8.28ポイント**
- 期待1着数195.04、実際165
- 日付クラスタブートストラップ95%区間（実際−予測の確率差）: -13.26～-3.31ポイント

ここは**未解決の高勝率帯の過信**であり、独自モデルとしてそのまま完成扱いしない。モデルへの補正係数を結果に合わせて今回の検証期間で後付けすればテスト独立性を失うため、この期間の予測CSVは凍結したまま保持する。

## 付記
2026年上期の既存モデル2検証（2,553レース）でも `R² = 1 - 1.5820768/1.9318559 = 0.181059`。これは既存のモデル選択過程で参照した期間であり、下期872レースを主証拠とする。

## 結論
**ベンターの原論文と同一指標の水準は満たしているが、競技間での真の予測能力の優劣は断定できない。さらに高確率帯で過信が残るため、独自モデル単独の完成には未達。**
