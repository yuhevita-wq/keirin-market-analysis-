# V6 / V6-C1 3連単フォーメーション生成器・説明書準拠版（研究用）

参照文献：ChatGPTライブラリーに登録された **`keirin_3rentan_formation_manual_latest.pdf`（全40頁、2026-10-30）**。PDFを読んでコード生成。説明書の例が収益性の保証でない点も準拠する。

## 発見した旧コードの設計欠陥

`research/v6_january_2023_formation_ev/prepare.py` の旧`select()`は、最初に市場オッズとモデル確率から個別の高期待値組番を探し、その1点を軸に固定した5種類 `fixed12`/`cross12`/`expand1`/`expand2`/`expand12` のみを候補生成。4〜12点の上限で、2着固定・3着固定・ハサミ・総流し・BOX・複数形などを適切に検討できなかった。**確率・オッズの高い組番を囲うことと、競輪の決着構造をフォーメーションとして表現することは別物。**

## 新実装

`research/manual_driven_formation/engine.py`（旧コードから独立）：

1. 入力は元V6または保存済みV6-C1の全3連単確率、出走表に公開済みのライン構成。**最初の候補生成ではオッズを使わない。**
2. ラインの連続役割、1・2着のペア、1・3着のペア、各着順候補の不確実性から、条件ごとに複数の**決着シナリオ**を列挙する。
3. 次のそれぞれ異なるフォーメーションを構成：
   - 1着固定・2/3着入れ替え
   - 1/2着の順序固定・3着流し
   - ワンツー表裏・3着全流し
   - 3人の1/2着入れ替え
   - 1着/3着固定のハサミ
   - 2着固定
   - 3着固定（逆流し）
   - 3車BOX / 4車BOX
   - 異なる決着シナリオの**複数フォーメーション合成**
4. 完全Cartesian各着順から不可能な同一車番を除外。複数形を合わせるときは重複組番を除外し**一度だけ100円**投資に数える。複数形をスロットで無闇に合併しない。
5. 買い目集合ができてから初めて実オッズを読み、複合オッズ・買い目集合全体の期待払戻・的中確率・点数・費用を評価。
6. 期待回収率の下限1.2、合成オッズ下限3.5は既存研究条件を暫定維持。4〜12点の硬直した範囲は撤廃。新しい最大40点は計算の上限であり、最適点数の主張ではない。
7. フォーメーションを一つの独立した買い目集合として評価する。個別組番に損得が混在しても容認する。
8. シナリオの名称・説明を買い目に付記し、ただの車番強弱比較や確率順位予想をフォーメーションへ代用しない。
9. 参加・見送りの検査 `admission.py` は、複数形を含む買い目集合の正確な重複除外を再計算できるよう修正。オッズに対する独立した市場優位性はまだ証明されていない。

## 安全性・再現性

- 元V6、V6-C1学習済み係数、表/裏ハルキュー、旧買い目生成コード、暗号化オッズ原本は**変更しない**。比較用の新しい研究ブランチに隔離。
- 2/3着が逆転していた暗号化オッズ原本は、既に327レース・74,034組番で確認した読み出し補正を継続し、公式払戻と一致しない時は停止。
- 予測には勝敗結果と払戻を渡さない。買い目を先にSHA256付きで固定してから公式払戻を読み出す。
- 元V6とV6-C1の2023年1月は学習期間内。未知期間の検証ではない。
- レースの実際の先行戦術、選手コメント、当日の風、走行状況などの情報は本研究用出走表には含まれず、**物語として捏造しない**。ライン役割と予測確率による条件付きシナリオに留まる。
