# G3・S級：2着独自モデル v1 — 実結果から導出

**研究対象は過去G3のみ。個別開催のレース分析は行わない。F1・S級の学習済み係数を使用しない。**

## 1. 母数とデータの独立性

- 旧保存ZIP 18本、2022年〜2026年上期の **G3・S級 8,995R** が1着独立モデルの対象。
- うち2着が一意で有効な **8,967R** を全件実結果の位置研究に使った。2着候補行は **69,620行**。残る28Rは2着結果が曖昧・欠損。
- 2022年の1,954Rは学習開始に先行するG3履歴がないため、その年を使って推定した独立1着確率を**標本内の参考観測**としてのみ使用。2023年以降の各年の1着独立確率は、それより前年までのG3のみから改めて推定。
- 2着係数の作成には2023〜2024年 **3,959R**、候補式の選択は2025年 **1,971R**、期間外確認には2026年上期 **1,083R** を使用。最終係数は2023〜2025年 **5,930R** から再推定。
- G3の1着確率に使う特徴量・正則化仕様は、先にG3の研究だけで選択したもの。既存のF1・S級学習係数や2着係数を一切引き継いでいない。
- 当時の出走表・予想ラインのスナップショットは後日取得であり、当時の締切前の状態との完全一致は**未証明**。

## 2. 実際の2着と、補正前のズレ

ハーヴィル式を基準として、実際の1着が `i` のとき候補 `j` が2着になる条件付き確率を `q_j/(1-q_i)` とした。`q` はG3専用の独立1着勝率。

| 1着との位置関係 | 補正前の2着予測回数 | 実際の2着回数 |
|---|---:|---:|
| **同ライン合計** | **2,563.1** | **4,882** |
| 別ライン | 6,403.9 | 4,085 |
| 同ライン・1着選手の直後 | 1,171.8 | **2,715** |
| 同ライン・1着選手より前方 | 1,295.6 | **2,053** |
| 同ライン・1着選手の2人以上後方 | 95.7 | 114 |

同ライン2着の実際の割合は **4,882 / 8,967 = 54.44%**。基準式の2,563.1 / 8,967 = 28.58%より大きい。単純な独立勝率から2着を割り当てる方法ではラインの同時入着を説明できない。

## 3. 最尤推定したG3独自の2着条件付き確率

\[
P(j\text{が2着}\mid i\text{が1着}) =
\frac{q_j^{\gamma}\exp[D(i,j)+R(j)]}
{\sum_{h\ne i}q_h^{\gamma}\exp[D(i,h)+R(h)]}
\]

**G3 2023〜2025年から推定し固定した7係数**：

| 数値パラメータ | 値 | 状態 |
|---|---:|---|
| \(\gamma\) 独立勝率指数 | **0.6389831175** | 採用 |
| 同ライン・1着の直後 \(D\) | **+1.6177727766** | 採用 |
| 同ライン・1着より前方 \(D\) | **+1.3898930066** | 採用 |
| 同ライン・1着の2人以上後方 \(D\) | +0.2955134610 | 採用 |
| 2着候補自身がライン番手 \(R\) | +0.0578434127 | 採用候補・追加効果は未確証 |
| 2着候補自身が3番手以降 \(R\) | +0.1419799936 | 採用候補・追加効果は未確証 |
| 2着候補自身が単騎 \(R\) | +0.2129563653 | 採用候補・追加効果は未確証 |

別ラインの位置補正とライン先頭の役割補正はそれぞれ0。各係数は正規化前の対数重みであって、そのまま確率と解釈しない。1着の直後の相対重み倍率は、他の条件が等しければ \(\exp(1.61777)\approx5.04\) 倍。

## 4. 2026年上期の期間外検証

**実際の1着車を知ったうえで2着を問う条件付き確率の対数損失**。小さいほど予測分布がよい。レース前の2車単的中率ではない。

| G3で比較した数学式 | 2着対数損失 | 2着確率1位の条件付き的中率 |
|---|---:|---:|
| ハーヴィル式（補正なし） | 1.758557 | 36.47% |
| 香港競馬ベンター指数0.81参考 | 1.741234 | 36.47% |
| **G3だけで推定した指数** | 1.741886 | 36.47% |
| 指数＋同ライン一律補正 | 1.528638 | 48.01% |
| 指数＋ライン内の前後位置 | 1.511661 | 48.38% |
| **指数＋前後位置＋候補選手の役割** | **1.510257** | **48.57%** |

2025年のモデル選択期間でも最後の式が最小対数損失だったため、選択した式を2023〜2025年で再推定した。2026年上期で係数の学習や調整はしていない。

日付単位クラスターブートストラップ（2026年上期87日）の改善95%区間：

- 選択したG3式 vs ハーヴィル式：**+0.24830**、95%区間 **[+0.19810, +0.30488]**。
- 選択したG3式 vs 指数＋同ライン一律：**+0.01838**、95%区間 **[+0.00907, +0.02742]**。
- **役割を追加した効果** vs 指数＋前後位置のみ：**+0.00140**、95%区間 **[-0.00091, +0.00362]**。区間が0をまたぐ。**役割による上乗せ改善は独立に実証されていない**。

よって、位置補正は数値で支持され、役割変数も2025年の損失基準により研究版の7係数として保存するが、役割そのものを一般的に有効な法則と断定しない。

## 5. 前もって1着を決めてはいけない

上の式は、確定1着が与えられた**研究時の条件付き確率**。未知レースで使用する際は、すべての異なる車番 `(i,j)` に対して

\[\boxed{P(i\text{が1着},j\text{が2着})=q_i P(j\mid i)}\]

を計算する。7車立てなら42通り、9車立てなら72通りすべてを列挙し、合計確率は1とする。あらかじめ「1着候補」を頭固定したり買い点数を設定したりしない。

## 6. 研究上の留保

- **G3の検証レース1,083R**はベンター論文の例3198Rと同じ母数ではない。ベンターの競馬予測モデルと数値の単純比較で予測能力の優劣は断定できない。
- 選定したG3独立1着モデルの特徴量群は2025年結果で選ばれている。したがって2023〜2025年の内部比較が完全な未使用標本評価であるとは主張しない。
- 歴史的出走表の事前情報の完全性は未認証。結果から式を発見することと、未来レースの締切前にそのまま通用するかは別の論点。
- **全券種オッズを使った市場価格誤差、期待値プラス、ベット配分は一切検証していない**。
- この研究はG3の2着で完結。3着式の研究や個別開催への適用はここでは始めない。
