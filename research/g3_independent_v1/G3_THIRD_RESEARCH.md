# G3・S級：実結果から発見した3着独自モデル v1

**2026年10月18日**。対象は保存済みの過去 **G3開催S級だけ**。F1・S級の係数、他グレード、個別開催の予想・結果を今回のモデル推定に含めない。

## 1. 研究順序と母数

1. G3・S級8,995レースの確定着順から、1・2・3着がいずれも有効で一意な **8,945レース**を得る。第三着候補は**60,506件**。
2. まず実際の3着選手の予想ライン内の位置を数える。基準として `q_k/(1-q_i-q_j)`（実際の1着i、2着jを条件としたハーヴィル式）との発生差を計算。
3. その実測偏りを説明するモデル群（指数のみ、ライン所属、役割、厳密な前後位置、前後位置＋役割）についてG3の結果だけから最尤推定。
4. 各年の独立1着確率qは、**2023年以降はその年より前のG3データのみ**で推定した値。2022年のqは2022年内標本なので位置の記述統計だけに使用し、3着係数の推定・選択・後期間評価には使わない。
5. **2023〜24年 3,950R**で候補係数を推定し、**2025年 1,966R**で候補モデルの選択。選定モデルを2023〜25年 **5,916R**で再推定。**2026年上期 1,081R**を後期間評価とする。

全候補・期間別値・誤差の生データ：[`g3_third_empirical.json`](output/g3_third_empirical.json)、[`g3_third_model_report.json`](output/g3_third_model_report.json)。

## 2. 何が実際の3着で起きていたか

| 確定1・2着との位置関係 | ハーヴィル予測の3着回数 | 実際の3着回数 |
|---|---:|---:|
| **1・2着の両方と同ライン** | 417.8 | **1,582** |
| 1着側ラインだけ | 1,089.8 | **1,309** |
| 2着側ラインだけ | 988.7 | **1,291** |
| どちらとも違うライン | 6,448.8 | **4,763** |

なかでも**同ラインで1・2着の後ろに位置する3着候補**は、基準予測186.2回に対し実績**1,269回**だった。この大きな残差を結果起点で発見した。

## 3. G3独自の3着条件付き数式

1着が `i`、2着が `j`、3着候補が `k`、G3専用の1着独立確率が `q_k` のとき：

\[
P(k\mid i,j)=
\frac{q_k^{\delta}\exp(D_{ijk}+R_k)}
{\sum_{h\notin\{i,j\}}q_h^{\delta}\exp(D_{ijh}+R_h)}
\]

研究版として固定した指数は **δ = 0.5016361541121158**（2023〜2025年のG3だけで推定）。

### ラインの相対位置補正 D（基準：両ライン以外＝0）

| 3着候補kの予想ライン内位置 | D |
|---|---:|
| 1・2着と同ライン、2人より前 | +0.921440 |
| 1・2着と同ライン、2人の間 | +1.442250 |
| **1・2着と同ライン、2人より後ろ** | **+1.817095** |
| 1着側ラインのみ、1着より前 | +0.718619 |
| 1着側ラインのみ、1着の直後 | +1.002133 |
| 1着側ラインのみ、さらに後ろ | −0.223910 |
| 2着側ラインのみ、2着より前 | +0.693088 |
| 2着側ラインのみ、2着の直後 | +1.130411 |
| 2着側ラインのみ、さらに後ろ | +0.102975 |

### 候補選手の役割補正 R（基準：ライン先頭＝0）

| kの位置 | R |
|---|---:|
| 番手 | +0.188732 |
| 3番手以降 | +0.408856 |
| 単騎 | +0.503837 |

位置を表す9種類の指標は相互排他的。「同じライン」の指標をさらに重ねて係数の非識別性を作らない。Rは役割の追加寄与として分け、正規化前の対数重みを変える。**係数や `exp(D)` を直接、3着確率と取り違えない**。

13係数（δ1＋方向9＋役割3）の全精度値は[`g3_third_conditional_v1.json`](models/g3_third_conditional_v1.json)に固定。

## 4. G3の数式同士を比較した結果

以下の評価は**確定1・2着が条件として与えられた場合の3着予測**。未知レースの3連単的中率ではない。

| G3第三着の候補式 | 2025年選択期間の対数損失 | 2026上期の対数損失 ↓ |
|---|---:|---:|
| ハーヴィル式 | 2.007720 | 2.040521 |
| ベンター競馬のδ=0.65（比較用） | 1.869826 | 1.897602 |
| G3だけで推定した指数 | 1.831820 | 1.851501 |
| G3指数＋1・2着のライン所属 | 1.663667 | 1.707492 |
| G3指数＋ライン所属＋候補役割 | 1.643758 | 1.706712 |
| **G3指数＋厳密な前後位置** | 1.641457 | **1.690915** |
| G3指数＋前後位置＋候補役割 | **1.634535** | 1.693720 |

**2025年のモデル選択ルールでは13係数の前後位置＋役割式が最良**。それを固定して再学習した結果、2026年上期の条件付き3着確率1位の的中率は**35.89%**。

ただし**2026年上期では方向だけの10係数式が対数損失で勝った**。日単位クラスターブートストラップ87日で、13係数が10係数に対して示した改善値は**−0.00281、95%区間[−0.00903, +0.00366]**。すなわち、役割補正の追加効果は統計的に証明できていない。

一方、方向10係数と単純なライン所属4係数の比較では、方向式の改善 **+0.01658、95%区間[+0.00228, +0.03155]**。方向情報の追加は後期間でも支持された。

この違いを隠さないため、**13係数を2025年選定による研究基準として保存し、10係数式の方が後期間対数損失が低かった事実も同じレポートに保持**する。13係数を無条件に「最良の普遍法則」と呼ばない。

## 5. レース前の全3連単順序確率

上記は確定1・2着を条件に推定したモデル。未来のレースで1・2着を知っていることにしてはいけない。これまで凍結したG3の1着独立モデルとG3の2着条件付きモデルに**G3の新しい3着式だけを接続**し、

\[
\boxed{P(i\text{が1着},j\text{が2着},k\text{が3着})
=q_i\,P_{G3}(j\mid i)\,P_{G3}(k\mid i,j)}
\]

をすべての異なる `(i,j,k)` に計算する。9車なら **504通り**、7車なら **210通り**。全確率の和が1で、1・2着周辺確率も既存のG3モデルと一致することを自動テストで検証した。
