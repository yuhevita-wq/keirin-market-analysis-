## 選定モデル・独立1着確率

候補は競走得点だけ、全基本指標、得点＋ライン、全基本指標＋ラインの4特徴量群、各3種類のリッジ係数から**2025年の対数損失が最低**のものを選択。

**選定結果：全17基本指標＋19のライン構造指標＋外国人カテゴリ／リッジ0.0001**。全候補モデルの係数はG3結果だけで最尤・正則化推定。

\[
P(i\text{が1着})=
\frac{\exp(\beta^{\mathsf T} x_i)}
{\sum_{h\in r}\exp(\beta^{\mathsf T}x_h)}
\]

ここで `x_i` は基準期間から標準化した選手・ライン特徴量と欠損フラグであり、オッズ・着順・払戻金は含まれない。

| 指標 | 2025年検証 1,981R | 2026年上期評価 1,085R |
|---|---:|---:|
| 対数損失 | 1.65365 | **1.67296** |
| ベンター式擬似R² | 0.23702 | **0.22915** |
| 1着勝率最大候補の的中率 | 39.42% | **37.42%** |
| 1着勝率上位2人への勝者捕捉 | 63.15% | **59.91%** |

2026年上期の1,085Rは、ベンター1994年の3198Rと母数が同じではない。競馬と競輪で出走数や難易度が異なるため、R²の大小だけでモデル優劣は主張できない。
