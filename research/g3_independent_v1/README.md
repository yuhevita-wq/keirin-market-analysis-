## 学習対象

- `data/grade_races/g3/` 内の2022年Q1〜2026年Q2、**18個の保存済みZIPのみ**を使用。
- G3開催のS級に限定。F1・F2・A級・ガールズ・G1・G2は混合しない。
- 有効1着が一意な出走表、5〜9車、発表された予想ラインを必須条件にする。
- 全体 **8,995R**。2022〜2024年 **5,929R** で各候補を学習し、2025年 **1,981R** で特徴量族と正則化係数を選ぶ。採用候補を2022〜2025年 **7,910R** に再学習し、2026年上期 **1,085R** で時系列評価した。
- 欠損・重複・除外理由は [cohort audit](output/g3_cohort_audit.json) に保存。
- F1研究の学習済み重み／校正係数は**一切転用していない**。特徴量生成のプログラム定義はコピーしており、G3だけで係数を独自に推定した。
- 特殊な期数 `term=999` は連続値として扱わず、希少二値カテゴリとして標準化せず扱う。
- 養成所期数や選手成績などの歴史的出走表は、後日2026年に収集されたもので、**当時の締切前の情報と一致することが未認証**。今の検証を厳密な当時の実運用検証と呼ばない。

## 選定モデル・独立1着確率

候補は競走得点だけ、全基本指標、得点＋ライン、全基本指標＋ラインの4特徴量群、各3種類のリッジ係数から**2025年の対数損失が最低**のものを選択。

**選定結果：全17基本指標＋19のライン構造指標＋外国人カテゴリ／リッジ0.0001**。全候補モデルの係数はG3結果だけで最尤・正則化推定。

\[
P(i\text{が1着})=
\frac{\exp(\beta^{\mathsf T} x_i)}
{\sum_{h\in r}\exp(\beta^{\mathsf T}x_h)}
\]

ここで `x_i` は基準期間から標準化した選手・ライン特徴量と欠損フラグであり、オッズ・着順・払戻金は含まれない。

| 指標 | 2025年検証 1,981R | 2026年上期評価 1,085R |
|---|---:|---:|
| 対数損失 | 1.65365 | **1.67296** |
| ベンター式擬似R² | 0.23702 | **0.22915** |
| 1着勝率最大候補の的中率 | 39.42% | **37.42%** |
| 1着勝率上位2人への勝者捕捉 | 63.15% | **59.91%** |

2026年上期の1,085Rは、ベンター1994年の3198Rと母数が同じではない。競馬と競輪で出走数や難易度が異なるため、R²の大小だけでモデル優劣は主張できない。
