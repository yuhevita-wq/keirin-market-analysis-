# 過去の途中オッズ収集 — 3券種

2026-10-19の依頼により開始。対象は2車複・2車単・3連複。
取得元 keirinodds.com の公開画面と同じクエリを使用し、指定日・会場・レースを検証して保存する。
3連単とワイドは研究データへ保存しない。ガールズは対象外。

## 実行・再開

`.github/workflows/collect-historical-path-odds.yml` の追加pushで最初の実行を開始。
手動起動と4時間ごとの再開にも対応。1回45分で区切り、途中の続きを保存する。
2026-10-18から過去へ遡り、探索下限2021-01-01まで取得元の開催を調べる。
2021年から全期間の途中オッズが存在するという意味ではない。返却のない日付は欠損として記録する。
5レースごと（最初の1レース後も）に保存。取得済みのレースと結果は再利用する。

実行環境: Python標準ライブラリ、curl。GitHub保存時のみgh CLI。

```bash
python research/odds_path_archive/collect.py --self-test
python research/odds_path_archive/collect.py --github --minutes 45
```

ローカルで少量を確認する場合:

```bash
python research/odds_path_archive/collect.py --minutes 3 --max-races 2 --end 2026-05-02 --output work/pilot
```

## 保存先

元データは公開コードへcommitせず、認証が必要なGitHubのDraft Releaseへ圧縮保存。
`path-odds-YYYY-MM` の `YYYY-MM-DD.json.gz` が日別レースデータ。
`path-odds-archive-index-v1` の `state.json.gz` が再開位置、件数、欠損記録。
Actionsの期限付きArtifactやCacheだけに依存しない。
コード・既存データ・他の収集ワークフローは改変しない。

## 保存内容

- 指定日、会場、R番号、級、実際の車立て、発走時刻、公式URL
- 3券種の実観測時刻、最終時刻ラベル、車券ごとの倍率
- 券種・時点ごとの収録件数、全組み合わせ件数、欠損フラグ
- オッズの取得URL・取得時刻・応答SHA256
- 公式の投票締切、3券種の100円当たり払戻、根拠となる公開HTML部分・応答SHA256

締切の取得に失敗したものを発走時刻から推測しない。
公式払戻が未確認ならpendingのまま残す。
取得元に記録された時刻と、今回遡って取得した時刻を混同しない。

## 採用範囲

上位50組までという制約を受け入れた研究用データ。
9車2車単72通り、3連複84通りのような場合は全組み合わせではない。
各投票判断時点で観測できた車券だけを対象にし、最終人気で事前候補を選別しない。
未収録を不的中、0倍、他時点の価格へ置き換えない。
単一時点の50組と、複数時点の和集合を区別する。
現時点では通常画面が要求する最大24時点を使用。全観測履歴の保証ではない。
収集はシミュレーション用の土台であり、購入ルールや勝率推定を確立したという意味ではない。

## 負荷・失敗処理

取得は直列、各取得間に最低1.5秒を置く。HTTP失敗は最大3回。
別日付・別レースへの代替応答を拒否する。
一時的に取れない日付はpendingに残し、以後のジョブで再試行する。
元データの利用条件: https://keirinodds.com/privacy
