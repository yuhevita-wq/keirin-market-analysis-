# F1・S級：過去データだけで生成する独立勝率（V7の前段）

この研究は **F1・S級のみ**を対象に、保存済みの出走表・予想ラインを使って、対象期間より前のレース結果だけで学習した独立勝率を期間別に生成する。A級・G級・ガールズなどを混合しない。

## 出発点とモデル

- 先行する [V2ライン込み独立1着勝率モデル](../benter_structural_discovery_v2/discover_v2.py) の **full_plus_line** と同じ特徴量・多項ロジット構造を使用する。
- 各対象期間の開始日を厳密な学習カットオフとし、その日以降の **結果をモデル学習に使わない**。
- リッジ係数は既存V2の値 \`0.0001\` に固定し、期間ごとの的中結果を見て選び直さない。これは既存研究から引き継いだ値であり、2024年当時に事前に選択済みだったことを意味しない。
- 2023年4〜12月を初期学習データとし、2024年Q1以降、四半期ごと（2026年7〜8月・9月は別期間）に学習を更新する。
- 各予測期間ごとに \`independent_win_*.csv\` と \`manifest_*.json\` を先にGitHubへコミットする。その後で初めて、当該期間の結果を後続の期間の学習に利用する。
- CSVに結果ラベルを入れない。Gitコミット・SHA256により後からの変更を監査する。

## 最重要の区別

これは現行V7の「独立勝率の元になるV2系の予測」作成工程であり、まだ **V7完成確率** ではない。

- 現行V7の2着・3着指数 \`γ\`/\`δ\` およびライン係数 \`a\`/\`b\` は一切変更しない。
- 現行V4の勝率校正係数は2026年7〜8月のデータで推定されているため、**2024・2025年の独立勝率へ遡及適用しない**。したがってCSVは未校正の独立1着確率 \`p_i\` である。
- 過去レースごとの履歴ページは、当時の数値を保存した出走表だと確認されている一方、完全な当時のライブ・スナップショットを証明するものではない。この系列を「完全に実運用時点で凍結した過去予測」と呼ばない。
- 過去のモデル選定に使った日付の結果は研究者が既に見たものであり、これを新規の完全ブラインド検証と呼ばない。
- オッズは独立勝率の特徴量に使用しない。

## 2段階処理

1. \`freeze_prior_win.py --period YYYYqN\`：過去結果のみで学習し、対象期間の予測と監査メタデータを生成。結果ファイルを対象期間の教師ラベルとして読み込まない。
2. 全対象期間のCSVがコミット・凍結された後に \`audit_frozen_sample.py\` を実行。初めて全期間の結果を照合し、1〜3着が一意であるレース、2着候補件数 \`Σ(n-1)\`、3着候補件数 \`Σ(n-2)\` を算出する。

利用期間を重ねない比較として、2024年〜2025年3月を研究学習、2025年4月以降を時系列評価に分ける。ただし、この分割の両群に原論文の規模を要求するのは**このプロジェクト独自の、原論文より厳しい監査基準**であって、ベンター本人が別々の3,198レースを使ったという主張ではない。
