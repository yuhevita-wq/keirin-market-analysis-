# 平買い利益探索 V2 — レース × 買い方 × 事前特徴

**V1の単独条件先行を廃止。** 「全組番を全部買うと60%」から出発しても、個々の買い方が利益になるかどうかは分からない。V2は先に車券を生成する複数の方法を用意し、各方法を過去の全利用可能レースへ例外なく平買い適用して、その損益を計算する。

## 何をするか

1. 2021〜2025年の保存済み男子競輪の3連単・3連複、**完全なオッズ表と検証済み着順が一致したレース**を全件処理。
2. 市場人気上位の1/3/6/12/24点、人気中位の帯、指定オッズ帯、1着候補の市場支持順位別など、**事前に定義した車券生成ポリシー**で100円平買い。該当しないレースは購入しない。
3. 並びが確認できるレースでは、同ライン1・2着、別ライン交差、番手頭、3車同ライン、3着別ライン、主ライン先頭・番手折返し等の買い方も対象。
4. 各ポリシーについて、レース種別・開催格・車立て・人気集中度・ライン構成・取得できる競走得点差・年齢等から、**無条件／単独特徴／異なる特徴の2条件ANDをすべて探索**。単独特徴が赤字でも、2条件同時の黒字を発見できる。黒字がゼロでも全条件の収支を出力して終わる。探索対象は「全組番の無条件購入」ではなく、各ポリシーが定める組番。
5. 結果を学習に使えるのは対象年より**前までのみ**。2021〜2022年から2023年を予測、2021〜2023年から2024年、2021〜2024年から2025年、2021〜2025年から2026年上半期の購入／見送りを凍結評価する。
6. 回収率100%超は発見の条件であり、実際の選別ルールには複数年の黒字、件数・的中数下限を別に使用。発見事実と未知年の再現性を混同しない。

## 大切な制約

- **全国全レースの完全収録ではない。** とくに2021〜2022年は保存済み市場が少ない。結果未確認は不的中ではなく検証不能。
- **2021〜2022年の同仕様の出走表・ラインがない**ため、選手関連の戦略を全5年に適用したとは言えない。2023〜2026年も出走表の保存範囲内だけで、line_idと番手が確認できる場合のみライン戦略を実行する。欠けたラインを結果から推測しない。
- 選手の競走得点・年齢を備えた出走表では、それらの差、強い選手の頭、弱い選手の頭、若手の頭なども検証する。ただし保存範囲は一部で、脚質・選手の生涯実績・過去相手関係の全面統合はまだない。現段階で「選手の必然条件」を発見したと主張してはならない。
- 着順データは的中判定のみに使い、買い方やレースの特徴としては使わない。
- 払戻は**確定オッズ×100円**の近似。取消返還・払戻公式値を未突合、実際の締切前オッズの再現ではない。
- 探索は**定義済みポリシー×2条件までの組み合わせ**であり、無限のフォーメーションや全ての可能な条件を網羅したわけではない。
- 高ROIの条件ほどサンプル数、年次変動、一発高配当への依存を点検すること。多重探索で偶然100%超の条件が出得る。
- ロジックは研究専用。既存の本番ハルキューの印、買い目、UI、判定を変更しない。

## 実行

リポジトリ直下:

```bash
python -m unittest discover -s research/flatbuy_pattern_v2 -p 'test_*.py' -v
python research/flatbuy_pattern_v2/engine.py --first 2021 --last 2025 --holdout 2026 --min-races 100 --min-hits 5 --min-years 2
```

GitHub Actions: .github/workflows/flatbuy-pattern-v2.yml

- PRでユニットテストを実行。
- mainへマージ後、**Run workflow**で実アーカイブの分析を手動起動。
- ダウンロード可能なActions artifactに以下を保存。

| 出力 | 概要 |
| --- | --- |
| all_flatbuy_cells.csv | 利益／赤字も含む全ポリシー×条件の実測件数・年別回収率 |
| report.json | 5年の黒字候補数、購入適格候補、トップ30、年度ごとの未知検証、ラインデータ充足 |
| walk_forward.csv | 未知年を買ったと仮定したレース数・点数・損益・回収率 |

V1は削除しない。V2結果と厳密に区別する。
