# オッズのみ・市場の誤値付け探索：2026-10-17 実結果起点の研究結論

この研究は**市場の偏りから離れた実結果の関係を発見し、損益分岐点を超える誤値付けを証明する**ためのもの。最終的な購入モデルは**未承認**。

## データと厳密な入力
- 保存済み完全3連単・3連複オッズと、レースID一致の実着順を照合。最大31,320レース。
- 研究年：2023年7,283、2024年8,147、2025年8,208、2026年上半期4,247。2021年1,076、2022年2,359も追加確認。
- オッズのみ特徴量。実着順は正解・払戻判定にのみ使用。ライン・選手名・得点・脚質などは一切入力していない。
- 保存済み**確定オッズ**。締切15分前の時点での再現性は未確認。
- 全7券種の暗号化保管データは現環境では復号できず、残り5券種は**未投入**。

## 問いの本質：市場の「外れ」と「予測誤差」は別
正規化した3連複市場確率を `qT(s)=(1/O3複(s))/sum(1/O3複)`、
正規化した3連単市場の6順序を加算した確率を `qS(s)` とする。
`D(s)=log(qS(s)/qT(s))`。
市場相対予測の誤差は `observed/expected`、投資上の損益分岐点は `P_real(s)>1/O(s)`。正規化した確率をそのまま損益分岐確率と混同しない。

## 過大評価の型（除外に有用）
`D(s)<=-0.15` の3連複は2025年、期待1,056.42的中に対して633的中、回収率37.23%。2026H1は期待589.23に対して393的中、回収率39.92%。
全組み合わせを買う場合の回収率は2025年58.14%、2026H1 60.73%。この過大評価領域を除いた残りを全部買っても2025年69.97%、2026H1 73.00%。**除外成功は黒字の証明にならない**。

## 過大評価の「発生源」から離れた結果
発生源：`D(s)<-.15`、`qT(s)>qS(s)` の組み合わせ。
発生源の市場間過剰支持質量 `M=sum_source(qT-qS)`。
別の候補 `t` が発生源と車番を共有しない部分を `F(t)=sum_source_disjoint_from_t(qT-qS)` と定義。
2023-24年に収益関連の型を探索し、2025-26年でそのまま検証。

1. 固定粗粒度帯の約2,601条件群では、2023/24各95%超の候補7件、2025/26両方で100%超は**0**。
2. 2023年のオッズ分布のみで発生源の質量 `M`、遠隔質量 `F`、離れた割合 `F/M` の分位帯を作った約5,446条件群では、2023/24各95%超の候補55件、2025/26両方100%超が**3**。ただし両年の個別回収率95%信頼区間下限が100%超だった条件は**0**。
3. 分位帯の細分化で見つけた候補は**多重探索に伴う偶然の当たり**である可能性が十分に高い。2025/26は過去プロジェクトでも既に何度か参照しているので完全に未使用のホールドアウトとは呼べない。

## 最も母数が大きい4年黒字条件（要検証）
3連複で、候補 `t` の市場人気順位が13〜24位、`D(t)>0.15`、
そのレースの発生源過剰支持質量 `0.0366855<M<=0.0428778`。
ここでは`F(t)`を条件に含んでいない。**発生源との車番非重複を条件にした利益発見ではない**ことに注意。

### 重要な脆弱性
- 2021年72%、2022年84%。
- 2025年前半130.41%、後半92.27%。
- 2026H1で最大払戻を1回除くとROI 89.89%（当該券のみ差し引く計算）。
- 質量帯を隣にずらすと2025年はROI 65〜89%程度に落ちる帯もあり、境界が非常に不安定。
- 7車以下/8車以上に分けると年ごとに結果が逆転する。すべての状況で同じ相関が成立しているわけではない。
- 遠隔源の距離 `F/M` ごとの小区分も利益の符号が安定していない。

**厳密な結論：候補は検出。利益になる市場間違いの確立までは未達。まだリアルマネー運用の推奨にはならない。**

## 次の数学的・データ的課題
1. 本来の全7券種を正規経路で復号、同じレースIDの実着順と結合し、各市場の確率的制約を比較する。2026H1までの市場価格だけでは、オッズ構造に残る強い割安領域を見落とす可能性がある。
2. 過大評価された券の価格誤差を**別の離れた結果に具体的に分配する写像**を学習する。今回の黒字例は全レースの発生源質量で層別しただけで、離れた元から特定着順までを証明していない。
3. 事前に市場誤差の定義、除外ルール、候補分布、買い目、点数および資金配分を凍結した上で、まだ見ていない新レースの締切15分前のオッズと実払戻で通期検証。
4. スコア改善、的中率の向上、チケットの実ROI、繰り返しの下振れを**別々に監査**。市場の誤りと儲けを混同しない。
