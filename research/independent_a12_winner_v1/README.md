# A級1・2班 独自1着モデル v1

## 目的
レースの出走表・公開並び予想から、各選手の1着確率を推定する。確率は当該レースで合計1。市場オッズ・人気・印・事後結果は説明変数に含めない。G3/S級モデルの係数は流用しない。

## 母集団
`data/a_class_12/2023_*/`〜`2026_05_06/` のA1/A2のみ、F1・F2の双方。5〜9車を許容。ガールズ・A3は対象外。出走者と結果の車番が完全一致し、1着が一意に確定したレースに限る。重複IDは処理を停止する。

## 特徴量
競走得点、直近4か月の1着率・2連対率・3連対率、B/S、逃げ・まくり・差し・マーク回数、年齢、A1所属、脚質、ライン先頭/番手/3番手/単騎、ライン人数、ライン内の他選手の最高得点差。出走表の各列は同レース平均を引いた相対値とする。欠測得点のあるレースは除外し、他の欠測数値は0扱いとして監査対象とする。公開並び予想がないときは役割特徴を0にする。後知恵の展開推測を禁止する。

## 確率式
各レースrの候補iの得点を `z_ri = beta^T (x_ri - mean_j x_rj)` とする。

`P_ri(1着) = exp(z_ri) / sum_j exp(z_rj)`。

係数は複数候補の競合を同時に扱う条件付き多項ロジット（L2正則化）で最尤推定する。全候補の1着確率合計は必ず100%。

## 期間分割
- 2023〜2024年：学習
- 2025年：正則化強度のみ選択・較正確認
- 2026年1〜6月：未使用の期間外検証。ここからパラメータを選ばない
- 提供用係数：選ばれた正則化で2023〜2025年から再学習

同じデータで調整・評価を繰り返さない。市場との結合・期待値推定・購入額決定は**別工程**。

## ベースラインと承認条件
競走得点1位のトップ1的中率、得点のみの確率モデルのlog loss、Brier、較正誤差と比較する。フルモデルが期間外で勝たなければ採用しない。収益率・期待値プラスは本工程では主張しない。

## 実行
```bash
python research/independent_a12_winner_v1/train.py \
  --data-root data/a_class_12 \
  --output research/independent_a12_winner_v1/report.json
```

出力JSONに採用件数・欠測・係数・ベースライン・検証値を記録する。成績数値は実行完了後にのみ報告する。

## 制約と追加監査
2026年に収集した過去の出走表が**当時発走前の情報を保存したもの**か、データ出所を別途点検する。印・評価・オッズ・着順情報の漏洩を防ぐ。2026年の検証はモデル開発後に都合よく期間を選び直さない。
