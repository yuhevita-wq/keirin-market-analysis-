# 基盤AIを固定した市場価格誤差の自己学習：第1回実験（2026-10-23）

## ユーザーの目標を復元

最上位目標は**公式払戻ベースの実現回収率を極限まで高める**こと。基盤AIの独自予測を市場に同調させることではない。モデルのlog-lossは内部診断に過ぎず、購入規則の採用基準ではない。

第2世代AIが学習済みの80,882レースの過去選手能力指標、および49,016レースのライン・A〜F分類を元に生成した**凍結予測**を入力とし、基盤AIのパラメータは変更しなかった。

## 実際に実行済みの反復学習

- 2025-01-01〜02-28の**3,704レース**（3連単/3連複合わせて7,408レース券種）を履歴として学習
- 2025-03-01〜03-31の**1,939レース**を購入ルールの自動選択に使用
- 2025-04-01〜04-19の**1,222レース**を診断に使用。**従前に何度も調べられた期間**であり、新規未使用のホールドアウトではない
- 6,865レースそれぞれの独立V2全組番予測（3連単210又は504通り、3連複35又は84通り）、暗号化された歴史的最終オッズ、既存WINTICKETライン特徴量、照合済みの公式払戻をレースIDと組番で結合。両券種計**1,916,880組番**。
- 3連単原本の2着・3着価格キー逆転は、すでに監査済みの**封印7市場アーカイブに限り**読み込み時に修正。的中組番の確認公式払戻と全件一致。

## 研究した2種類のエージェント

### 比較・棄却：着順教師あり補助予測器

`P'(組番)=normalize[P_base(組番) exp(x組番・w)]` で上乗せ差分を教師あり学習したが、基盤の価格情報を打ち消し、市場に近づく傾向が再発。この方式を最終予測・購入モデルに昇格させない。3連複予測は3連単6順列の合計に整合。3月条件選択・4月確認で**54.45%**。

### 本命の研究方式：実払戻の金融残差を逐次学習

基盤AIの確率 `P_base(組番)` は**一切修正しない**。

```
予測基準価格 = P_base(組番) × 市場オッズ
実現収益倍率 = 的中なら公式払戻額 / 100円、それ以外は0
金融残差(教師信号) = 実現収益倍率 − 予測基準価格
補助価値予測 = 予測基準価格 + online_ridge(事前ライン・型・価格差特徴)
```

金融残差学習は競輪当日の結果・払戻を**予測時には一切使わず**、日次決着後の追加入力として利用する。オンラインの正規方程式を積み上げて翌日の予測係数を計算。**市場確率を正解ラベルにしない**。購入候補・券種・点数は予測スコアから決まる。試験の資金単位は比較用100円/点。券種は**公式払戻との正確な組番対応が確認できた3連単・3連複のみで先行学習**、対象の選好として固定したのではない。他券種の公式払戻拡張処理を追加し、データ品質確認中。

3月に自動選択された金融残差モデル：公式払戻での回収率 **71.68%**。しかし4月診断では **54.00%**。4月の**前日結果で毎日係数を更新するprequential版は53.44%**。

現在の**導入許可はゼロ**、基盤AIのパラメータと継続収集の原本は不変更。**回収率が上がらなければ自動学習器を昇格しない**。検証段階で不利益の大きいモデルを無理に使うことは禁止。

## AIの反復学習手順

(1) 独立基盤が先に予測 → (2) 同時点の市場価格との差を全組番で推定 → (3) 全レース終了後に公式結果・公式払戻で教師信号を算出 → (4) 市場誤差エージェントの係数を**翌日以降にだけ**更新 → (5) チャンピオン基盤との回収率を比較 → (6) 未使用期間で収益性の証明が済むまで本番モデルを昇格しない。

市場価格が確定後に記録されているため、現状の全ての収支は**後日確定オッズによる反実仮想**であり締切前に実際に購入できたことの証明ではない。2025年4月20日以降の予約済み検証期間の公式結果はこの学習では参照していない。
