# 全7券種：基盤AIアンカー型・金融残差の反復自己学習（2026-10-23）

## 研究原則
**最高順位の目標は回収率。** 既存V2基盤AI（80,882レースの過去能力指標＋49,016レースのライン/A〜F検証から作った凍結済み組番確率）は絶対に「市場と同じ確率へ近づける」目的で変更しない。学習器は基盤確率と全市場価格の**実際の払戻に対する誤差**のみを追加学習する。

### 実際に完了
- 独立V2予測・保存済みWINTICKETライン・封印オッズ市場・公式払戻を2025年1月〜4月19日の**6,865R**で突合。
- 3連単/3連複/2車単/2車複/ワイド **各6,865R**、9車のみの枠単/枠複 **各685R**。全市場レース単位 **35,695件**、候補**2,569,575組番**。
- 1〜2月3,704R：価格残差を公式払戻教師信号で学習。3月1,939R：係数・購入条件選抜。4月1〜19日1,222R：**以前にも分析済みの診断期間**（新しいOOS検証ではない）。
- 同じ4月に、1日予測→全レース公式結果を観察→**翌日から**モデル係数更新する日次自己学習も実行。基盤AIの組番確率・重みは変更していない。
- 購入候補は各市場の全組番から抽出し、最大点数・頭固定・固定フォーメーション・券種除外を課していない。試験の共通比較単位100円/点は本番購入ルールではない。

### 金融残差の教師信号
```
独自基盤の期待回収倍率 = P_base(組番/事象) × 保存済み市場オッズ
実際の回収倍率 = 公式払戻円/100（的中）、それ以外0
教師信号 = 実際の回収倍率 − 独自基盤の期待回収倍率
購入候補スコア = 独自基盤の期待回収倍率 + 市場価格誤差エージェントの逐次推定残差
```
オンラインの正則化線形回帰（ridge）で、候補組番のライン・位置・A〜F・市場価格・基盤AIとの食い違いを学習。**市場確率を正解として回帰していない**。学習は教師ありの歴史リプレイ（AlphaGo型のシミュレーション自己対戦とは別）。

### 重要な元市場ファイルの組番キー監査
- 暗号化市場原本の**3連単**は **2着/3着が逆の市場キー**（6,865/6,865公式払戻と一致する補正）。
- **2車単および枠単**は **1着/2着が逆の市場キー**（各6,865/6,865、685/685の公式払戻と一致する補正）。
- **3連複/2車複/枠複**は通常の組合せキーにより一致。
- **ワイド**は保存オッズが配当レンジなので、20,595公式的中払戻が全件レンジ内にあることを確認。購入判定には保守的な下限、実収支には正確な払戻を使用。
- 9車立ての枠への対応は独立した公式2車単/枠単決着 **685/685照合**で確認。
- 以上は元の「封印7市場オッズアーカイブ」の**専用価格読み込み変換**に限定し、別ソースの市場キーを変更しない。
