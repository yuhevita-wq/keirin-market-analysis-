# Market Probability v1 — 市場確率補正（研究版）

**目的:** 結果を「当てる」のではなく、3連単の **全着順** について市場の条件付き確率を出発点にし、出走表・ライン・3連複市場の情報で残差を推定する。市場に勝てたかは未来方向の検証データで **log loss / Brier score** を比較して判定する。

## モデル

各レースの全3連単の確定オッズ `O_i` から `q_i=(1/O_i)/sum_j(1/O_j)` を計算。

```
p_i(theta) = q_i * exp(X_i @ theta) / sum_j[q_j * exp(X_j @ theta)]
```

市場そのまま (`theta=0`)、市場の人気温度だけ再調整（1パラメータ）、出走表・ライン・市場間の差による多変量補正を **同じ評価レース** で比較する。

- 事前入力: 全3連単オッズ、全3連複オッズ、出走表の競走得点・勝率・3連対率・B/S・決まり手の過去集計・年齢・脚質、公開された予想ライン。
- 市場間特徴: 3連単の6通りを足した3選手集合確率と、3連複市場確率の対数比。
- **厳禁:** 結果、払戻、順位、決まり手の当日結果、払戻人気などを特徴量に含めない。
- 7車を上限とする。取消・欠損・不完全な市場は除外し、その数を報告。重複するS級予選データはrace_idで除外。

## 研究上の時系列

1. **2023年**: 学習（S級F1全レースの4〜12月＋S級予選の未重複を追加）。
2. **2024年**: 正則化係数の選択・検証。ここは純粋な最終テスト扱いをしない。
3. **2025年**: 2023〜2024年で再学習したモデルを時系列検証。
4. **2026年1〜6月**: 2023〜2025年で再学習したモデルを時系列検証。既存研究で触れているので完全未使用とは呼ばない。

市場そのもの・市場の温度調整だけ・多変量補正の3者のlog loss/Brierを公開し、ブートストラップではなく独立レース近似で平均log loss改善の標準誤差・95%区間を提示する。「勝てる」と言うには両方の市場ベースラインより改善し、時期を越えて安定し、別途取得した締切前の執行可能オッズで検証する必要がある。

## 実行

```bash
python -m pip install numpy scipy
python research/market_probability_v1/train.py --self-test
python research/market_probability_v1/train.py
```

GitHub Actions: `.github/workflows/market-probability-v1.yml`。結果ファイル:
- `data/audits/market_probability_v1_2023_2026.json` — 年別予測比較、統計、対象件数、データ制約
- `data/models/market_probability_v1_s_f1_2025.json` — 2025年末までの係数（**確定オッズ研究専用**）

**注意:** すべてアーカイブ済みの「確定オッズ」で学習・評価する。これは投票締切の後でしか確定しないため、実際の購入時点で利用できる予測モデルではない。モデルに利益計算を載せる部分は参考・事後的な上限の研究であり、実際の投票で買える価格・自身の購入額による価格変化・市場容量・控除率・執行時刻等を満たしていない。回収率が100%を超えても勝利の証明ではない。

A級とG1/G2/G3は結果・出走表が保存されていても、対応する全組み合わせのオッズが揃わない範囲はこの市場残差モデルには投入しない。非対応データを混ぜて擬似的にサンプルを膨らませない。

v1は最終成果ではない。「事前スナップショット」「市場の厚み」「A級などの全オッズ」「新しい未来レース」が追加されない限り実運用は保留する。
