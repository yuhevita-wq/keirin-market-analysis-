# ベンターの着順補正式を競輪実結果で検証（2026-10-18）

## 原論文の方法
出典：W. Benter (1994), *Computer Based Horse Race Handicapping and Wagering Systems*, p.192–194、式(7)–(9)。
\[
P(i,j,k)= p_i
\frac{p_j^{\gamma}}{\sum_{a\neq i}p_a^{\gamma}}
\frac{p_k^{\delta}}{\sum_{b\notin\{i,j\}}p_b^{\delta}}.
\]
- \(p_i\) = 既存の独自モデル2によるオッズ非使用の勝率、各レース合計1
- ベンター本人の競馬で推定した係数は \(\gamma=0.81,\;\delta=0.65\)
- 旧Harville法は \(\gamma=\delta=1\) で、2・3着の条件付き勝負を過信する傾向がある。
- ベンターはこの係数を他の競馬場でも共通としないことを明記。

## データ分割・独立性
- 係数学習：2026年7月2日〜8月30日、F1 S級、予測875R、1〜3着が一意な**867R**（8R除外）
- 完全凍結後の結果照合：2026年9月1〜30日、F1 S級、予測422R、1〜3着が一意な**419R**（3R除外）
- 1着確率の元データは結果閲覧前に別コミット済みの \(p_i\)。9月の1着確率と1着校正済み値も、9月結果取得前に別コミット済み。
- 7〜8月でγとδを二段階の条件付き対数尤度最大化から推定。**9月結果では一切再学習しない。**
- ベンター原論文通り、まず本来の独自モデル \(p_i\) に適用して比較。追加でV4の確率校正済み \(q_i\) にも適用。
- 全券種のオッズ・回収率等は一切この検証に使用しない。

## 最尤推定パラメータ
| 期間 | 2着γ | 3着δ |
|---|---:|---:|
| 競馬・ベンター本人（1994） | 0.81 | 0.65 |
| 競輪・7〜8月全体（元勝率） | **0.766619** | **0.289993** |
| 競輪・7月（元勝率） | 0.746110 | 0.321152 |
| 競輪・8月（元勝率） | 0.790786 | 0.252959 |
| 競輪・7〜8月全体（V4校正済み勝率） | 0.783778 | 0.292829 |

係数が低いほど、低勝率選手の2・3着確率を広く割り振る。競輪の3着は1着勝率に比べて大幅に拡散する傾向を示す。

従来式→競輪専用係数の独立期間外改善：
- 2着：0.013514（30日クラスタbootstrap95% −0.003235〜+0.028839、ゼロを含む）
- 3着：0.116266（+0.056133〜+0.177616、改善の証拠あり）
- 3連単順序付き：0.129781（+0.066132〜+0.195970、改善の証拠あり）

**ベンター本人の係数→競輪専用係数**：
- 2着：改善0.000186（区間 −0.00297〜+0.00302）
- 3着：改善0.022403（区間 −0.00839〜+0.05355）

=> 競輪専用係数はベンター本人係数よりテスト値が良かったが、**確証は得られない**。

9月の条件付き2着の最多確率候補的中：143/419、3着の最多確率候補的中：142/419。指数正数による確率順位は変わらないため、これらの的中数も方式間で同じ。改善は当該組合せに与える**確率の精度**であり、単純に1番人気をよく当てる仕組みではない。

## 解釈に関する重要な留保
1. この式が示すのは、**実際の1着が既知の条件付き2着確率**、実際の1・2着が既知の条件付き3着確率、そしてそれらを掛けた事前3連単順序付き同時確率。
2. 2・3着に固有のライン相互作用や位置・脚質の残差モデルを独立には学習していない。原論文の方法で校正しただけ。
3. 2026年9月は独立した後時系列テストだが、競馬と競輪で競技構造が異なる。香港競馬の係数0.81・0.65を普遍定数と解釈しない。
4. これをもって市場に勝った・期待値正の車券を発見したとは言えない。オッズは未使用。
5. 学習・検証範囲はF1 S級であり、A級・G競走・9車一般には無条件で外挿しない。
