## 問い：市場とAIのズレに収益性はあるか？

AIと3連単市場の不一致だけに入る戦略は、モデルの過信を「市場の誤差」と誤判定することがある。

## 仮説（事前にコードで固定）：全組番期待値ではなく着順条件付きの構造的矛盾

元V6と保存済みV6-C1の双方が、同じ3連複組み合わせの中の3連単「着順」を市場より1.5倍以上高く予測する組番を少なくとも2点、しかも異なる3連複組み合わせ2種類以上確認できること。併せて3連複市場との予測比は両モデルとも0.75〜1.35、フォーメーション全体の予測平均回収倍率は両モデルとも1.2倍以上。原本不一致なら見送り。

**この閾値は黒字条件を後付けで探索したものではないが、利益を保証する経験的根拠もない。** あくまでも試験仮説。

## 検証で判明した重大な整合性エラー

原本を「確定オッズ」としてそのまま採用できない。

- 保存済み暗号化オッズの該当組番を100円購入した場合の計算上の払戻と、独立の公式払戻アーカイブの額が、V6-C1全購入で**826的中中825件**不一致（**一致は1件、0.1211%**）。
- 従来のV6-C1全購入（公式払戻確認できる4,747レースのみ）の実払戻合計は2,339,100円／投資3,654,300円（64.01%）。ただし110件の的中では公式払戻欠損がある。
- 一方、暗号化原本の価格を払戻へ換算すると4,857レース全体で10,526,120円／投資3,738,600円（281.55%）という**公式払戻と整合しない値**になる。この高回収率を実収益として使用禁止。
- 旧方式と新方式の条件比較は、価格対応の根本問題が解決するまで実運用へ移さない。現時点では、公式払戻を確認できた範囲で新方式51.31%、全購入64.01%であり新方式は好転していない。いずれも有効な市場価格検証ではない。
- **現段階では、価格原本側・レースID結合・単位・払戻アーカイブ側のどれが原因か確定できない。** 単純に暗号化オッズが誤りと決めつけない。

## 結論・固定方針

1. 公開用6,301レースを「2023年の全オッズ」と見なさない。暗号化原本まで照合する。
2. **公式勝ち組番の払戻と元の価格が一致するか**の監査が通るまで、期待回収率、誤差選別、利益シミュレーションの評価を停止（fail closed）。
3. 選別機構のない従来方式（全レース購入）は不採用。新ゲートは研究候補止まり、実運用には組み込まない。
4. 価格と結果の一致が修復されたら、レースごとの採用／見送り・券種・点数・フォーメーションを同じ事前固定条件で評価する。
5. 2023年2〜4月はV6・V6-C1とも学習期間内の再現実験であり、未知期間利益の証明には用いない。
