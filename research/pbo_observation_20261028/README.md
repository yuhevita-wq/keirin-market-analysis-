# 研究観察002：過去の１位を選ぶ手続きの観察

2026年10月28日。既存の年度集計から新しく選択・順位を再計算した記述的観察。正式なCSCV/PBOではない。

対象：2023〜2025年の既存1,882レース、前半・中盤・後半それぞれ６種類の２点候補。全試行履歴や13万件全体の評価ではない。

| 区分 | 選択→確認年 | 選択年１位の回収率 | 翌年回収率 | 翌年順位（６候補） |
|---|---|---:|---:|---:|
| 前半 | 2023→2024 | 124.6% | 103.6% | 3位 |
| 前半 | 2024→2025 | 297.0% | 57.5% | 2位 |
| 中盤 | 2023→2024 | 436.3% | 81.9% | 2位 |
| 中盤 | 2024→2025 | 127.8% | 97.3% | 2位 |
| 後半 | 2023→2024 | 123.1% | 0.0% | 6位 |
| 後半 | 2024→2025 | 98.4% | 76.1% | 4位 |

観察：６比較すべてで回収率が低下。５比較で翌年赤字、２比較で翌年下位半分。後半2024年の選択年１位も赤字だが、比較のため強制的に１位を選択している。購入推奨ではない。

暫定結論：過去の１位の成績をそのまま次年度へ期待できない事例がある。順位が上位でも赤字の場合があるため、論文のPBO（相対順位）と損失確率（絶対収支）は区別する。

限界：年度比較は重複しており独立な６試験ではない。2/6を正式なPBOと呼ばない。既存集計の組番・払戻は今回原本から再照合していない。この観察だけで不振原因を過剰適合と断定しない。
