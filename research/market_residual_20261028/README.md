# 市場残差 D の実データ検証

実行: `python research/market_residual_20261028/verify.py`

テスト: `python -m unittest research.market_residual_20261028.test_verify`

対象は組番修正後の保存済み集計、2021年〜2026年6月、133,673レース、4券種です。既存のオッズ帯8区分を使用し、年別と全期間の224セルを再計算します。区分は今回の結果に合わせて変更していません。暗号化原本を今回再走査したものではありません。

市場評価は投票資金割合の直接観測ではなく、各レース・券種の全組番について逆数オッズを正規化した近似値 q=(1/O)/sum(1/O) です。D=sum(y)-sum(q) は保存済み的中数と市場期待的中数から再計算できます。重複するprice_cars、price_type等は合算しません。

全買い目のDは恒等的にほぼゼロとなります。これは市場が正しい証拠ではありません。帯別の正負の相殺を確認する対照です。4券種・各年で的中数と期待数が対象レース数に一致することを検査します。

三連単では5倍以下の実績/市場期待が1.1241、D=+1251.94、最終オッズによる回収率近似82.98%。1000倍超は0.6911、D=-1294.12、回収率近似46.19%。これらは記述統計であり、日・レース内依存を考慮した有意差認定、未知期間での検証、実購入による利益の証明ではありません。原集計の品質保証を継承しており、今回独立した原票監査は行っていません。

results.jsonには原集計SHA-256、原集計生成コミット、除外件数、限界、全セルと相殺対照を記録します。results.csvは全セルの表です。
