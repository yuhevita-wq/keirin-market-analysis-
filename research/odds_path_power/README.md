# 論文検証に必要な量で収集を終えるための標本数計画

対象論文は Hanyu et al., arXiv:2509.14645v3。
競輪への適用検証であり、競馬単勝の完全再現や実購入の利益の証明ではない。
原論文の付録C.3が指摘する「最終価格を見た後に投票できない」制約を保持する。

## 主目的と停止条件

3券種（2車複・2車単・3連複）について、同程度の最終オッズでも価格経路と実現収益の関係が残るかを、別期間で検証できる量を集める。
有意差やプラス収支が出るまで収集を続ける設計にはしない。

- 主な計画基準: 相対的なオッズ10%低下に対応する回収率差 **3.4ポイント**。
  これは論文Table 2の約3.4ポイントを参照した暫定の検出対象であり、競輪の実測効果とは主張しない。
- 家族内の第1種過誤5%を3券種でBonferroni調整し、計画上の検出力90%を目標にする。
- 2、5、10ポイントを対象とした必要数も感度分析として保存。
- 基本式 return ~ final_odds + change + final_odds*change に、取得済みの場・級・車立て・年月の固定効果を加える。
  原論文の全属性統制を再現したものではない。
- 同一レースや同日の買い目を独立な試行として数えない。標準誤差は日付でクラスタ化。
- 必要なレース数と日付数の両方を計画する。
- 予備データから残差分散・価格変動・クラスタ構造を推定し、日付再標本化による上側の分散推定で保守的な目標を設定。
- 少なくとも30日付クラスタを得るまでは計画を確定しない。30日だけで十分という意味ではない。
- 最初に計画が算出できた時点で固定し、予備データの全レースIDを登録する。
- その予備データを除いた別期間の有効レースが、3券種すべての目標に達したら新規取得を停止する。
  チェックポイントは5レースごとのため最大4レース程度の余剰はあり得る。

## 有効データの条件

公式締切・公式払戻が確認済みで、締切5分前以前の最新観測があり、その時刻のずれは最大120秒。
指定時点より後の価格を前の価格の代わりに使わない。
同じ買い目の確定オッズも存在するものだけを基本回帰に使い、予備段階で欠損を集計する。
上位50組に限ることと、両時点の共通集合に限ることによる選択制約が残る。
この範囲の検出力計画を、未収録の低人気車券全体へ一般化しない。

「有効レース」は各券種に少なくとも1つの有効ペアを持つレース。
独立試行単位の代わりに観測行数315万などを目標に使用しない。

## 保存と運用

収集ジョブの前後に監査を行う。新しい収集ジョブも直ちに起動する。
GitHub Draft Release `path-odds-power-plan-v1` に次を保存する。

- sample_plan.json.gz: 固定した計画、推定方法、予備レースID、必要数
- sample_status.json.gz: 券種別の有効レース数・日付数・充足判定
- Draft Releaseの説明欄にも実行状況を掲載

凍結後は有意性や観測された効果の大きさを見て必要数を下げない。
データが計画上の条件を満たしても、論文の主張が支持されるとは限らない。支持・反証・不明のいずれも報告可能な設計。
必要数が取得元の収録量を超えた場合は、十分と偽らず不足として報告する。
計画上の検出力は、予備と確認期間の共分散・クラスタ密度・価格分布が概ね比較可能という仮定に依存する。
