# 🐣 競輪AI育成室 — 本物の第1世代

## ユーザーから赤ちゃんAIへ渡す唯一の説明

> 出走表とオッズを見る。マークシートに券種・車番・金額を書く。
> 3連単は「1着–2着–3着」の着順を指定、3連複は3車を順不同で指定する。
> 1点100円で記入する。結果は予想提出後に教わる。

**初期モデルの重みは全て0。** 既存のGEN-001（market_probability_v1）、ビル・ベンター、市場モデル、ライン理論、強い選手の選び方、頭固定、買い点数戦略等は**教えない**。初期予想は自由度を保つため、ランダムな探索と汎用的な学習器で決まる。

## 何を1週間やるか

1. GitHub内の2023年のA級（A1/A2）、A3チャレンジ、S級、G1〜G3の出走表を読み、レースIDで全券種オッズと結果を突合する。
2. 先に着順を覗くことはしない。欠損や矛盾のあるレースは補完せず記録する。
3. 参加可能な共通データの最古の日から連続7暦日を対象とし、開催・級班・車番を好みで絞らない。
4. 日時順に全レースを出走表＋当時の確定オッズで再現し、マークシート（100円1点）を先に凍結する。
5. 予想提出後に着順を開示し、学習重みを**1レースごとに更新**する。
6. 7日分の予想・正誤・日別変化・最終学習重みをすべてGitHubへ保存。
7. GitHub Pagesの /ai-lab/ に経過を可視化する。

## "赤ちゃん"の実体

外部LLMや学習済み競輪モデルではない。0重みの単純なオンライン数値モデル。出走表の汎用的な数値・カテゴリとオッズのみを機械的に符号化する。最初のレースでは固定知識を持たず、賭式と買い目を確率探索で選ぶ。結果を教えられるたびに正しいマークへの確率を高める数学的更新を行う。モデル内部の実装は汎用であり、レースに対する思想や購入ルールを教えない。1レース1点100円は初歩マークシート練習用の記入形式であり、実際の推奨購入資金ではない。

## 履歴とチェックポイント

- outputs/GEN-001/mark_sheets.jsonl: **結果を見る前に書いたマークだけ**を収録。
- outputs/GEN-001/learning_history.jsonl: 各レース終了後の結果、正誤、更新前後の重みハッシュ。
- outputs/GEN-001/checkpoint.json: 1週後の学習重み。
- outputs/GEN-001/summary.json: 1週間の詳細監査。
- docs/ai-lab/nursery-*.json: 可視化と閲覧用データ。

## 重要な保存データ上の限界

- 2021年から確定オッズと結果はあるが、同期間のすべてのA級・S級の出走表が保存されているとは確認できない。よって出走表との共通形式がある2023年を探索する。
- 全国すべてのレースのデータが完全に揃っているわけではない。**対象週のA・S・A3・グレードレースを故意に除外せず、欠損レースは明記**する。
- GitHubの統合公開オッズで使えるのは3連単と3連複。全7券種の暗号化保管庫は復号鍵なしに利用できない。別券種を捏造しない。
- 締切前オッズの記録ではなく**確定オッズでの歴史的な模擬学習**。出走表も後から保存されているので、厳密な実際の予想再現ではない。
- 成績中の払戻額は確定オッズ×100円の参考値であり、公式払戻の厳密な代用ではない。
- これは1週間の教育、勝率・回収率の有意性や予測能力の検証ではない。

## 実行

    python -m pip install numpy
    python research/ai_nursery/train_week.py
    python research/ai_nursery/test_week.py

GitHub Actions: `.github/workflows/baby-ai-first-week.yml`。この実行は、新しい学習履歴と重みをGitHubへ自動コミットする。ユーザーが求めた通り**第1世代を赤ちゃんから育成する**ためのもので、以前の完成モデル群は教材として使わない。以前の第1世代モデルは、混同を避けるため独立した過去の研究アーカイブとして扱う。

## 🧬 第2世代 GEN-002 (2023-01-08〜14)

第1世代の2023-01-07チェックポイントを**そのまま継承**した子世代。新しくフォーメーションマークシートと枚数無制限の記入手段を渡して482レースを経験。第2世代の結果は `outputs/GEN-002/` に固定保存。出走表・オッズ・正解を見せる順序は以前と同じ。フォーメーションの記入方法以外に競輪の理論は教えていない。詳細は `GEN-002.md`。

今後は **新能力を与えたときに世代番号を進める**。同じ能力のまま継続訓練した場合は同世代の次週として別保存する。

## 第3世代 GEN-003（2023-01-15〜21）

GEN-002の学習重みを引き継ぎ、最初の仮想資金10,000円と残高不足時の10,000円補充だけを新しく教えた。用紙は無制限のまま。出走表と確定オッズから先に全マークを保存し、結果を見せて学習する。補充回数、総入金、紙上車券損益、最後の財布を分けて保存する。詳細はGEN-003.md。

## 🎁 第4世代 GEN-004（2023-01-22〜28）

GEN-003の学習重み・財布残高を引き継ぎ、財布が10,000円を超えたら超過分をそのままご褒美として別口座に移す。ご褒美が生じた予想マークの特徴も学習で追加強化する。従来の結果学習、フォーメーション、足りなくなったら1万円補充、A級・S級全種の参加方針などは変えない。詳細は GEN-004.md。

## ⚡ 第5世代 GEN-005（2023-01-29〜02-04）

GEN-004の重みと財布と累積ご褒美を継承し、1万円分の仮想財布を使い切って補充が必要になるたびストレス（負の機械学習信号）を与える。結果開示後の学習・フォーメーション・資金補充・ご褒美は継続。補充時のストレスと車券の実損益を分けて保存。詳細は GEN-005.md。

## 🧪 同じ未学習レースでの成長試験と行動学習の品質規約

固定試験は2023年6月1〜7日。第1〜5世代の保存済み予測重みで、同じレースを新たな学習なしに評価。予測（対数損失/Brier）・行動（用紙枚数/見送り）・成果（紙上収支）を分ける。次世代からは学習可能な参加/見送り・用紙終了方針、1点ごとの報酬帰属を使用。テスト期間のデータで育成・最適化をしてはならない。詳しくはGROWTH_AUDIT_PROTOCOL.md。

## GEN-006（28日間の育成）

2023-02-05〜2023-03-04。GEN-005から重み・財布・ご褒美を継承し、参加/見送り、用紙の続行/終了について行動方針を逐次学習する。旧世代のような固定50%打切りには戻さない。毎Rの行動ログ・用紙を結果前に凍結し、結果後に予想と行動の重みを更新。2023年6月の共通試験は学習から除外し、訓練チェックポイントの保存後、別Actionsで成長試験を実施する。詳細 GEN-006.md。

## 🎯 GEN-007（純収支プラスが唯一の目標）

2023-03-05〜2023-04-04（31暦日）。GEN-006の予測重み・行動方針重みを継承。購入した車券の総払戻−総購入額を**厳密に0円より大きくすること**だけを目標とする。全見送りの0円は失格。財布・資金補充・ご褒美・ストレスは既存履歴の会計のみで、行動判断や利益判定には使用しない。履歴と共通未学習試験で改善を検証する。詳細 GEN-007.md。

## GEN-007・同世代2ヶ月継続（2023-04-05〜06-11）

追加能力を与えずGEN-007のまま、元の重み・行動方針を継承。2023-04-05〜05-31の57日と06-08〜11の4日で61学習日。06-01〜07は既存固定試験を保護し完全除外する。前向き検証は07-01〜07の別ホールドアウトへ移す。唯一の成功判定は純収支プラス（投票0点は失格）。元のGEN007重み・用紙・履歴は保持し、outputs/GEN-007/continuation-2m に区別して保存。詳細 GEN-007-C2.md。
