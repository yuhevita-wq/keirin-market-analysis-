# 表ハルキュー：市場価格形成・レース選別の独立研究 v1

**既存の表ハルキュー・裏ハルキュー・本番Webは変更しない。**

2026-03-21固定の表ハルキューLightGBM／44特徴量／HIGHゲート・車券・点数・資金配分は全て維持。
このプログラムは `research/market_probability_v1/train.py` に既にある全3連単の確率分布と市場補正係数を再利用し、別個に「どのレースの市場誤差が投票成績と関係するか」を検査する。

## 検証契約

- 2023年：確率モデルの学習。
- 2024年：9種類の事前宣言されたレース選別条件を比較し、条件を満たす場合にだけ1つのゲートを選ぶ。
- 2025年：2023–24年で確率係数を推定し直し、2024年で選んだゲートを固定適用。**購入条件の再選択はしない。**
- 2026年上半期：2023–25年で確率係数を推定し直し、同じゲートで再検証。既存研究で分析済みのため、完全な未知期間とは呼ばない。

全候補 `c` に対し `p(c)=q(c)*exp(X(c)*θ)/sum_all[q*exp(X*θ)]` を求め、合計確率が必ず1になるようにする。損益分岐の基準は **p(c)*O(c)>1** であり、正規化市場支持確率そのものではない。

選別角度は「最大補正EV」「補正を半分に縮めても維持されるEV」「3連単と3連複の市場不一致」「過小評価候補が少数に集中する度合い」など。選別パラメータは2024年のみで決定。該当する候補が存在しなければ採用せず、2025/26の結果を見て選び直さない。

## 範囲と認定条件

今回は既存の`market_probability_v1`研究に従い、S級・最大7車・出走表と全決着オッズが揃う対象だけ。A級等の完全カバーは主張しない。

使用するのは保存された **確定オッズ**。表示オッズ×100円で計算した収支は「参考の払戻代理値」であり、**実際の公式払戻記録で照合した収支ではない**。T-15で買えたオッズでもない。2025年・2026年上半期も研究全体では既に見られた履歴。したがって **この実験だけで未来利益を証明したとは判定しない**。

実売買へ進む条件は、研究期間から独立した未来のT-15スナップショットと当日の公式払戻を照合し、レース別購入／非購入ログ、控除、資金配分、月別収支、損失連続期間と信頼区間を公開すること。
