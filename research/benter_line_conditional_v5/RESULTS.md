# ベンター式V5 — 競輪のライン条件付き2着・3着モデル
実施：2026-10-18。市場オッズ・結果確定後の説明用展開・払戻率は使っていない。第1目的は2着・3着の**実現条件付き確率**と全3連単確率の改善。

## 1. 競輪専用の正規化確率式
\[
P(1=i,2=j,3=k)=q_i\,\frac{q_j^{0.702788}\exp(L_2(i,j))}{\sum_{a\ne i}q_a^{0.702788}\exp(L_2(i,a))}
\,\frac{q_k^{0.345816}\exp(L_3(i,j,k))}{\sum_{b\notin\{i,j\}}q_b^{0.345816}\exp(L_3(i,j,b))}.
\]
- \(q_i\)：既存の市場オッズ非使用、独自モデルV2＋V4校正で得る1着確率。
- 0.702788、0.345816、および下記のライン効果は**2026年7〜8月の867レースだけ**で学習。従来の無ライン式では2着0.783778、3着0.292829。
- 全ての異なる車番 \(i,j,k\) に対する事前の順序付き確率の総和は1。
- ベンターの論文が採用した、条件付き2着→条件付き3着という構造を保ち、各段に**着順固有のライン効果**を足す。
- \(i,j\) は予測対象候補として走査する。予測時に実際の1・2着が判明していることは**必要ない**。
- 2着や3着のモデル内に着順結果を特徴量として使わない。学習時のみ事後ラベルを用いる。

### 2着モデル \(L_2(i,j)\)
前回7〜8月係数学習で得られた係数：
| 条件（候補j） | 係数 |
|---|---:|
| 1着候補iと同ライン | +0.662630 |
| iが先頭、jが番手 | +0.167281 |
| iが番手、jが先頭 | +0.243875 |
| 同ラインでjがiより後ろ | +0.357660 |
| jが番手 | +0.163060 |
| jが3番手以下 | +0.000561 |

個々の条件は重なる場合がある。選手の強さを単純に並べるのではなく、**1着になった場合に同時入着する2着候補の位置関係**を条件として持つ。

### 3着モデル \(L_3(i,j,k)\)
| 条件（候補k） | 係数 |
|---|---:|
| kが1着候補iと同ライン | +0.121389 |
| kが2着候補jと同ライン | +0.121126 |
| i,j,kが全員同ライン | +0.091645 |
| i先頭→j番手→k3番手の順序 | +0.035513 |
| kが番手 | −0.022716 |
| kが3番手以下 | +0.059896 |
| kが同ラインでiより後ろ | +0.093842 |
| kが同ラインでjより後ろ | +0.101147 |
| 候補kのラインで上位2人以外に残る人数 | −0.162635 |

ラインは公開されたレース前の**並び予想**を使用。係数の単体符号は交互作用を含むため、原因や単独の効果と決めつけない。

## 2. 実結果から見えた構造
学習：2026年7月2日～8月30日、F1 S級予測875Rのうち着順が一意でライン有効な867R。
- 実際に1・2着同ライン449R（51.8%）、別ライン418R。
- 1・2着が同ラインだった449Rでも3着まで同ラインは133R（29.6%）。3着は残る別ライン316R（70.4%）。
- 1・2着異ラインの418Rでは、3着は1着ライン129R、2着ライン134R、第三ライン155R。

検証：2026年9月、422Rから着順同着など3Rを除外した419R。
- 実際1・2着同ライン225R（53.7%）、別ライン194R。
- 1・2着同ライン225Rのうち3着まで同ライン68R（30.2%）。別ライン157R（69.8%）。
- 1・2着異ライン194Rでは、3着が1着ライン71R、2着ライン68R、第三ライン55R。

**最重要**：1・2着の同時入着を強く読むことと3着を同ラインに固定することは違う。

## 5. 未解決
- **3着はなお難しい**。9月419Rにおける実際1・2着が既知の場合、3着候補がそのいずれかのラインに属する確率について、元の無ラインモデル平均予測32.4% → V5平均予測39.1%と改善したが、実際は49.4%。残る構造誤差は約10.3ポイント。
- 3着に残った別ラインの中で誰が候補か、個人の位置・ラインの対戦構造の細分化が未完了。
- 同ライン以外の条件、例えばライン間の先頭×番手の相関、2車ライン対3車ラインの残存、実際の隊列の移動などは未検証。
- 9月結果は前回の無ライン研究で既に使用したため、**全研究における真の盲検ホールドアウトではない**。改善の独立再現性は、今後新たな未使用期間で判定すべき。
- あくまでF1 S級。A級やG1/G3・9車に自動的には転用できない。
- 全券種の市場オッズ未使用。**3連単購入で期待値＋となる保証はない**。現時点では独自モデルを完成と呼ばない。
