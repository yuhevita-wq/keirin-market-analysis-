# 型ラボ：全履歴80,882レースから1着・3着内確率を学習（2026-10-23）

## 実行結果

- 全7券種オッズの暗号化原本134,336レースから、過去着順に基づく安全な能力指標が生成された80,882レースを入力。
- GitHub Actions： [39866107675](https://github.com/yuhevita-wq/keirin-market-analysis-/actions/runs/39866107675) **success**。
- 公式払戻との比較で隔離された同着188件、結果未確認663件、および選手識別子の矛盾等に該当するレースは予測データへ混入させない。
- 学習：2024年6月まで**35,816レース**。確率補正：2024年7月〜12月**11,579レース**。未学習テスト：2025年1月〜2026年6月**33,487レース**。
- 推定器：選手ごとの prior-only 能力特徴量（過去勝率・2/3着内率、直近30/90/365日、相対Elo、履歴量、出走間隔等）の線形スコアを Plackett–Luce 順位尤度（1→2→3着）に適合。温度補正T=**1.186489**は確率補正期間のみで選定。
- **同じ順位分布から周辺確率を計算**するため、全選手の1着率合計は1、3着内率合計は3、各選手のP(3着内)>=P(1着)。別々の独立ロジスティックモデルのような論理矛盾は生じない。

## 未学習期間の確率予測評価（2025〜2026年上期）

低い値がよい。原資金の回収率ではない。

| 評価指標 | 均等選択（車数に応じた1/n・3/n） | 本モデル |
|---|---:|---:|
| 1着多クラスlogloss | 1.9678318 | **1.6668555** |
| 1着多クラスBrier | 0.8599120 | **0.7614133** |
| 3着内二値logloss | 0.6778315 | **0.6150703** |
| 3着内二値Brier | 0.2424167 | **0.2132206** |

改善は、1着loglossで約15.3%、3着内Brierで約12.0%。これは単純な均等確率との比較であり、オッズ、選手得点、既存強モデルを超えたことの立証ではない。

3着内0.8〜0.9と予測した区間のテスト実測率は約0.8016（区間内平均予測0.8436）。0.9以上の区間では実測0.8983（平均予測0.9335）。**高確率帯の過大評価が残る**ため、現段階では確率をそのまま期待値プラス買い目判定に使わない。

## 全量データによる最終モデルを別途構築

未学習テスト評価を保存したあとで、別の **80,882レース全件で再適合したモデル**を生成した。

- `pl_full_80882_production_model.jsonl.gz.cms` はオーナーのCMS証明書で暗号化された最新版モデル。
- 最終学習に使用した最後のレース日は **2026-06-30**。
- 最終版に用いた確率補正温度は2024年下期で校正した固定値。**最終版自身に対する未学習期間テストは存在しない**。上表の検証成績は2025年以前に係数を固定した検証用モデルの結果であり、最終版の成績だと誤記しない。
