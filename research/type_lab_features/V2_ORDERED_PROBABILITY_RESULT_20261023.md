# 型ラボ第2世代：条件付き3連単・3連複組番確率AIの実装結果（2026-10-23）

## 実施したこと

**2023〜2025年保存済みWINTICKET 49,016レース**のライン所属、ライン内位置、競走得点、脚質、ちぎられ率、A〜Fに必要な荒れ度情報と、**2021〜2026上期に再構築した80,882レースの前日以前の履歴能力指標**を組み合わせ、3車の同時入着確率を再学習した。

旧モデル：2024-06-30以前でPL係数学習、2024下期で温度補正した固定ベースライン。第2世代：`P(i,j,k)=P(i)P(j|i)P(k|i,j)` の3段の条件付きロジット。ライン所属・先頭/番手位置・前順位との差・ラインクロス・競走得点差・荒れ度等の **22特徴量**を加える。3連単の全順列は総和1、3連複の組合せは6順列の和で総和1。学習・評価とも市場オッズ・事後着順・実払戻を説明変数に入れない。

## 厳格な時系列分割

- **学習**：2023-01-01〜2024-06-30の30,572レース
- **補正**：2024-07-01〜2024-12-31の11,579レース
- **完全未学習テスト**：2025-01-01〜2025-04-19の6,865レース
- 2023/24年の型は、**2026年まで含む全履歴で再学習したPLモデルの型ラベルを特徴に使わず**、2024年6月に固定したPLのp3とWINTICKET原本のラインから元の式で再計算した。このため過去の分類との一致率は**45,603/49,016（93.04%）**であり、不一致3,413件は旧分類のまま学習に使用していない。
- データ分割の日付を跨ぐ目的変数の流出なし。独立109開催日の信頼区間を算出。
- 元のWINTICKET継続収集、原本Release、masterブランチの変更なし。

## 全組番EV>1の検証でも依然として不合格

2025年の確定後の**最終オッズ**と第2世代の全3連単/3連複の組番確率を比較して、`確率×最終オッズ>1` の買い目をすべて100円買う仮定で、独立にアーカイブ化された公式払戻と突合した。

| | 3連単 | 3連複 |
|---|---:|---:|
| 購入点数 | 652,776 | 78,942 |
| 購入額 | 65,277,600円 | 7,894,200円 |
| 公式払戻 | 39,366,980円 | 5,087,810円 |
| **回収率** | **60.31%** | **64.45%** |

**確率が上がったことと市場の価格ミスを検出できたことは違う。** 第2世代の確率からはまだ市場超過期待値は確立されていない。研究はこの状態を成功ROlと装わない。最終オッズは締切15分前の約定可能価格ではない。

3連単原本の `3rentan` 組番は市場価格の記録側で2着/3着が逆のため、元原本の市場キーのみ変換し、公式払戻の順位を変更しない。2025年の実払戻対市場換算6,865件で一致検証済み。

## 成果物
会話に提供する `type_lab_v2_joint_probability_ai_20261023.zip` に、学習スクリプト `type_lab_v2_joint_order_model.py`、市場監査 `type_lab_v2_market_audit.py`、統計検査 `type_lab_v2_diagnostics.py`、報告3JSON、**第2世代学習済み重み** `v2_model_parameters.jsonl.gz.cms` と **未学習6,865レースの全組番確率** `v2_heldout_ordered_probabilities.jsonl.gz.cms` を保存。私有鍵は同梱せず、所有者の証明書で暗号化した。

実装済みで未実施：過去に存在した第2世代を本番15分前のデータで毎R更新するデプロイ工程、市場に対する正の期待値の選別式、購入点数/金額の最適化。今後必要なのは組番別・オッズ帯別の**条件付き校正と市場確率との統合**、新たな時間外期間の再検証。
