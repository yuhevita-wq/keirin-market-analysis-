# 型ラボ A〜F 分類：正本固定・全量入力・不足データ監査（2026-10-23）

## 原本と定義

正本：`nyanta-kun/kiseki` の `keirin/src/type_lab.py`、Git blob SHA `50a4bd2c2c1861702e13cbd46bc1f38b9b065d85`。

- `S = p3` 上位2車の合計、**生の p3** を用い、`S >= 1.44` を堅い A/B/C、未満を混戦 D/E/F と判定。
- `arare` は、最大 `p3` の選手のライン人数（2人なら+1、4人以上-1）、ライン先頭の遅れ率（11%以上なら-1、未満なら+1）、先頭脚質「追」（+2）、開催日目 `day_index-2`、番手得点が先頭を超える（+1）を加算する**正本そのままの式**。
- `arare<=-1 / =0 / >=1` で A/B/C または D/E/F が決まる。欠けた入力をゼロ補完しない。
