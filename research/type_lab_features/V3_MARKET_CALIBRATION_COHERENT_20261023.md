# 第3世代：組番確率と市場の統合・条件付き校正（2026-10-23）

## 実装・実測
直前の第2世代AIの **2025年未学習6,865レースの全3連単・3連複確率** を使用。独立の公式払戻原本、同じレースの全組番市場確定オッズを照合。3連単は **元の封印7市場アーカイブに限り、2着・3着の価格キー逆転を訂正**（他の市場へ一般化しない）。

時系列分割：1〜2月 **3,704R学習**、3月 **1,939Rで校正方式選択**、4月1〜19日 **1,222Rの未使用最終テスト**。使用したオッズは**レース終了後の最終値**、締切15分前の可取引価格ではない。

市場事前確率は `q_j=(1/o_j)/sum_l(1/o_l)`。予測p2との全体log-opinion統合（`log q + alpha(log p2 - log q) + beta log q`）と、A〜F型別／最終オッズ帯別のridge校正を、1〜2月の公式着順で学習し、3月のloglossで方式を選択。収益率で方式を選んでいない。

|4月未学習logloss、低いほど良い|3連単|3連複|
|---|---:|---:|
| 第2世代単独 | 4.32503 | 2.80493 |
| 市場正規化のみ | 3.94860 | 2.57127 |
| 個別統合最良 | 3.94627 | 2.56612 |
| **同一3車確率で整合した最終版** | **3.94627** | **2.56212** |

両券種を個別に統合しただけでは事象確率が矛盾するため、同じ3車の3連複確率を必ず3連単の**6順列合計**と等しくする整合モデルも構築。`H_g ∝ G_g^(1-λ) × B_g^λ` とし、各順列を `H_g/G_g` 倍する。λは3月だけで校正し **λ=0** が採択。今回の最終モデルは3連単の市場統合確率を集計したものを3連複確率として採用する（3連複の市場情報を追加で採用していない）。

2025年4月・19暦日単位5,000回ブートストラップの市場単独比「勝者への対数確率改善」の95%区間：
- 3連単：平均 **+0.00233**、区間 **−0.00032〜+0.00495**（ゼロを跨ぐ）
- 3連複：平均 **+0.00915**、区間 **+0.00077〜+0.01787**（プラスだが小さい。19日しかない）
