# 重要な訂正：第3世代の「3連単0点」は市場誤差発見の成果ではない（2026-10-23）

## 原因
第3世代の対数統合は `log P(c)∝ log q(c)+0.01605973 log(p2(c)/q(c))+0.04886919 log q(c)`。
`q(c)=(1/O_c)/Σ_j(1/O_j)`。独自モデルの市場との差の係数が **0.016** と著しく小さく、ほぼ市場価格だけのモデルになった。

2025年4月1〜19日、1,222レースで市場逆数オッズ総和の中央値 **1.3363**（市場だけの期待回収倍率0.7483）。正式第3世代の全3連単全組番を調べても推定回収倍率の**最大は0.8565**。このためEV>1は0点。1〜2月・3月も正式第3世代ではすべて0点。

この結果は「市場の誤差が存在しない」の証明ではなく、**市場へ近づける総合確率校正を市場誤差の検出器として代用した設計の不適合**を示す。

## 独自モデルの係数を増やすだけでも駄目
2025年4月の同じ1,222レース・公式払戻・固定対数混合 `Pα ∝ q^(1−α)p2^α`：

|α|3連単EV>1点数|回収率|
|---:|---:|---:|
|0.016|0|非購入|
|0.10|1,119|18.00%|
|0.20|31,215|70.52%|
|0.50|95,186|58.06%|
|1.00|109,654|58.73%|

元の独自モデルも価格に対して多数の**偽のプラス期待値**を出していた。2025年4月の `p2/q >= 2` の3連単67,410点はモデル期待的中約400、実際104、ROI **54.99%**。1〜2月60.88%、3月57.37%と同方向。

## 研究方針の修正

- **研究順序を実決着→全券種オッズ→条件別残差→価格形成規則→独立検証へ戻す。**
- 総合logloss最小化の市場融合は**比較ベンチマークとして保管**し、買い目判定器・市場誤差発見の完成版と呼ばない。
- 残差をライン同線/異線/位置・車数・A〜F・市場価格帯・p2対市場相対評価ごとに、**市場が想定する発生率と実発生率**の両方で研究する。係数・条件は先に固定せず、学習窓で発見したものを別期間へ照合する。
- 実際にどの型が価格過小評価か検定するときは、**資金・実払戻・的中点数・日別変動・信頼区間・多重比較**を必ず報告する。
- 3連単の原本組番の2・3着逆転は原本を変更せず読み込み時に補正、3連複確率は必ず3連単6順列の合計。
- 2025年4月は既に多数の研究で覗いたため、**次の新しい本番外検証期間として再利用しない**。収集済みの後続WINTICKETデータが結合できた段階で新しい固定検証を実行する。
- 研究用には購入不可でも**全組番の価格誤差ランキング・型別分布を出す**。ただし期待値プラスが証明できなければ購入は見送り。買わせるための数字を捏造しない。
