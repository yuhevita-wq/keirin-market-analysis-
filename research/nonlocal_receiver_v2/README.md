# 結果起点のオッズ偏り探索：除外→候補→買い目（2026-10-17）

この研究は**現時点で実購入モデルとして不合格**。勝った式として配布・昇格させない。

## 厳密な入力
- 特徴量：3連単、3連複の確定オッズのみ。全候補の価格分布、両市場の食い違い、候補と車番が一致しない他の組み合わせからの偏り、相互作用。
- 実着順は、学習の正解ラベルとバックテストの払戻判定のみ。ライン・選手名・競走得点・出走表は不使用。
- 照合31,320レース。2023年7,283レースで学習、2024年8,147レースで確率混合を校正、2023+24で再学習、2025年8,208レース、2026年上半期4,247レースに適用。
- 残り5券種は暗号化済み保管データがあるが平文照合しておらず**未分析**。確定オッズなので締切15分前の実行可能性も未検証。

## 発見：離れた偏りと実結果の不一致
2023年のオッズ分位点で固定した遠隔符号特徴の最小グループ：
- 2025年実際2,268件 / 市場期待2,160.557件 = 1.04973倍
- 2026年実際1,202件 / 市場期待1,121.517件 = 1.07176倍
最大グループ：
- 2025年実際1,041件 / 市場期待1,082.554件 = 0.96162倍
- 2026年実際590件 / 市場期待658.528件 = 0.89594倍
ただし、この偏りを**利益の出る券種選択**に使えるとの証明ではない。

## 除外能力（購入とは別）
各レースの上位50%の3連複候補を残す（下位50%を先に除外）：
- 2025年の真の的中集合を92.373%保持。市場だけでは89.455%。
- 2026年の真の的中集合を92.607%保持。市場だけでは89.345%。
92%は高く見えるが人気情報による基準の89%との差は約3ポイント。

## 結果から偏りを学習した木モデル：遠隔特徴の追加価値
実結果の対数損失（低い方が良い）を本番より後の2期間で比較：
- 2025: 自身のオッズ情報だけ2.821723、遠隔特徴追加2.820417（改善0.001306）。
- 2026上半期: 自身のオッズ情報だけ2.802316、遠隔特徴追加2.803806（悪化0.001490）。
つまり遠隔特徴は現時点で**時系列で安定した予測上の改善ではない**。

## 「残す候補」と「買う券」を分離した実購入検証
同じ2023/24学習済みモデルで、後期候補を上位25%,50%,75%,100%残して、EV閾値0.9,1,1.03や損失分散の罰則を検証。

- 3連単、上位25%のみ残す、モデル期待値>1.03、各100円：
  2025年1,986点、回収率112.860%、利益25,540円。
  2026上半期1,080点、回収率73.056%、損失29,100円。
  合計3,066点、投資306,600円、利益-3,560円、回収率98.84%。
- 3連単、上位50%のみ残す、推定期待値>0.90（**利益条件ではない探索的ストレス試験**）：
  2025年31,494点、回収率97.773%。
  2026上半期16,284点、回収率89.332%。
  合計47,778点、回収率94.90%。
- 3連複、上位50%のみ残す、推定期待値>0.90：
  2025年13,562点、回収率86.391%。
  2026上半期7,861点、回収率101.733%。
  合計21,423点、回収率92.02%。

24条件（保持率4 × 閾値3 × リスク罰則2）×券種2 の比較において、**2025と2026の両方で100%を超えた同一購入条件はない**。結果を見て2025/26から条件を選んでも、未知の将来に通用する証拠とは言えない。

## 何が間違っていたのか
1. 一部のp×オッズ>1券だけで買う判定をしていたため、候補が消える理由を検証しなかった。
2. 対数損失が少し改善することを購入優位と混同。対象券種の払戻分布や高配当での予測誤差に弱い。
3. **結果から偏りの対応関係を見つける探索**より先に、期待値フィルタだけでフォーメーションを出そうとした。
4. 初期の小点数で黒字だった式は大数で試すと崩れ、保持候補と購入券を分離したものでも時系列の黒字を維持できていない。

## 次の研究で守るべき順番
- 実結果→全券種オッズの対応をレースIDで厳密照合（暗号化分は鍵を保持する正規経路で復号してから使用）。
- 全結果候補 × 全オッズの偏りについて、観測発生と市場期待の差を母数・信頼区間付きで推定。車番の交差/非交差、遠隔などは候補特徴であって結論ではない。
- 過大評価される候補を除外するルールは時間的検証に固定し、**真の結果の取り逃しを測定**。
- 残りから購入最適化を行う際は、同時買いの損益分布・一撃集中・リスクを用いる。単一券の推定p×O>1を無条件に全購入しない。
- 事前固定した式をまだ触っていない後日レースのT-15価格と実払戻で監査。**継続的な100%超が確認できるまでは不合格**。
