# 全級別データの共通入口（all_classes）

2026-10-29 に、誤って削除された S級データを Git 履歴（退避ブランチ `archive/s-class-source-folders-20261029`）から復元し、既存の A級1・2班、A級3班、グレードレースとともに見つけやすくした**整理用フォルダー**です。

## ディレクトリ

- `s_class/2023/`, `2024/`, `2025/`, `2026_h1/`, `2026_future_block1/`: 年度ごとの S級ソース。元の `data/2023/`, `data/2024/` 等も復元済み。
- `a1_a2/`: 元の `data/a_class_12/` と同じ内容。
- `a3_challenge/`: 元の `data/a3_challenge/` と同じ内容。
- `grade_races/`: 元の `data/grade_races/` と同じ内容（ほかの S級データ等と重複する可能性があるため、単純加算禁止）。
- `odds_s_class/2023/`, `odds_s_class/2026_future_block1/`: 誤削除された `data/odds_universe_v1/data/` 配下の S級市場ソースも復元して参照できるようにしたもの。

## 原則

1. **元のディレクトリとファイルは削除しない。** このフォルダーは Git のツリー参照を使った無変換の整理用コピーで、既存のプログラムのパスを維持する。
2. **複数の収集バッチを無条件で結合しない。** 対象期間・対象級班・開催種別が異なり、同一レース ID が重複する可能性がある。利用時は race_id とソース・取得条件で重複チェックする。
3. **並びの有無はデータごとに確認する。** A3 の `races.csv` などにはライン列がないものがある。ライン推定や結果からの遡及的補完はしない。
4. **「全級の完全な単一データセット」が生成されたわけではない。** ここは集約入口であり、未収録レース・結果・オッズの網羅率は別途監査する。
5. 予測には必ずレース前に利用可能な情報のみを使い、結果で翌日以降に更新する。
