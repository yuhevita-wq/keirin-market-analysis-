# 寬仁親王牌・世界選手権記念トーナメント 初日 過去問用出走表

2021年から2025年までの初日全12Rを、既存G1/G2アーカイブの `entries.csv` から抽出した盲検用データです。

## 入っているもの
- レース日、競輪場、レース番号、レース種別、発走時刻
- 車番、選手名、府県、年齢、期別、級班、脚質、ギヤ、競走得点
- S/B、逃・捲・差・マーク回数、1/2/3着・着外回数、勝率・2連対率・3連対率
- 出走表取得時点のライン情報（並び、ラインID、位置、役割等）

## 入れていないもの
- オッズ、人気、投票数
- 着順、結果、上がり、決まり手、結果コメント
- 払戻、的中組合せ
- 予想印、評価文
- 元URL、取得時刻、raw HTML行JSON

対象日は、各年10月のG1から「12R開催が4日連続するブロック」を一意に検出し、その初日だけを採用します。一意に決まらない場合は生成を失敗させます。
