# 男子競輪：レース種別＋確定オッズ専用データ

## 対象

- 2021年1月1日〜2025年12月31日：男子競輪の全レースを収集対象とする
- 2026年1月1日〜6月30日：男子競輪の全レースを収集対象とする
- **2026年7月以降・ガールズは収集・統合対象から除外する**
- A級・S級、F1・F2・G1・G2・G3、すべてのレース種を対象とする（ただし欠損は未解決）

## ファイル

- `odds_all.jsonl.gz`：全対象年をつないだgzip圧縮JSON Linesファイル。大きくなりGitHub容量制限を超える場合は年別で扱う
- `odds_2021.jsonl.gz`〜`odds_2026.jsonl.gz`：年別。**2026は上半期限定**
- `../audits/odds_only_export.json`：年別実収録件数、完全性検査、重複処理、SHA256などの別管理の監査結果

データ本体に入るキーは **`race_id`、`race_type`、`odds` の3つのみ**。選手・ライン・競走得点・結果・払戻データはデータ本体に含まない。

## 現時点で収録している券種

**3連単・3連複のみ**。全組み合わせの数値オッズが確認できたレースだけを統合する。2車単・2車複・ワイド・2枠単・2枠複は未統合。全車券種を既に収録済みと誤認しないこと。

全国すべてのレースが収録済みという意味ではない。日本全国の開催一覧を独立して走査し、レース未収録と確定オッズ欠損を区別して追跡する。

## 収集・品質管理

- `research/odds_universe_v1/scope.py`：2026上半期限・女子除外
- `nationwide_calendar.py` / `compare_calendar.py`：全国のレースIDを収集・突合
- `recover_unarchived.py`：保存されていない男子レースを新規取得
- `backfill.py`：A級・S級の欠損オッズ補完、最大3回までの再試行
- `grade_archive_repair.py`：G1〜G3の欠損修復
- `build_odds_only.py`：重複除去、確定オッズ全組合せ検査、年別・全期間統合

取得できない価格はゼロや推測値で埋めない。提供元の自動取得・再配布条件も確認すること。
