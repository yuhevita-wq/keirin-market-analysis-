# 競輪分析 / 2025戦略シミュレーション

競輪の過去データを収集・構造化し、**2025年を対象に戦略をシミュレーションしてプラス収支を目指す**研究用リポジトリです。

## プロジェクトの大前提

この研究では、全レースを同じものとして扱いません。

- 予選、敗者戦、準決勝、決勝など、**レース種別によって戦略を変える**
- **レース番号によって荒れやすさ・配当分布が変わる**という仮説を検証する
- 最終的には `レース種別 × レース番号 × レース構造 × 戦略` の単位で成績を比較する
- 2025年の結果を見た後に都合のよい条件を追加する後付け最適化を避ける
- 戦略変更はGitHub上で履歴を残し、変更前後を区別する

## 現在の第一段階

まず **2025年の「Ｓ級予選」** を対象に、出走表を全件収集します。

対象表記は完全一致の `Ｓ級予選` とし、現時点では以下を混ぜません。

- Ｓ級予選１ / Ｓ級予選２
- 一次予選
- 特別選抜予選
- その他の別名称レース

対象範囲は今後、検証単位を明確にしたうえで追加します。

## 収集する出走表データ

主な項目:

- 開催日
- 競輪場
- レース番号
- レース種別
- 発走時刻
- 車番
- 選手名
- 府県
- 年齢
- 期別
- 級班
- 脚質
- ギヤ
- 競走得点
- S / B
- 逃 / 捲 / 差 / マ
- 1着 / 2着 / 3着 / 着外
- 勝率 / 2連対率 / 3連対率
- 取得元URL
- 取得時刻

取得・解析できなかったものは推測で補完せず、失敗ログとして残します。

## ライン構成

楽天Kドリームスに掲載されている**「並び予想」**を取得して保存します。

これは公式確定ラインではないため、データ上では `predicted_line_formation` として明確に区別します。

例:

```text
6-1-5/7-2/4-3
```

レース単位ではライン全体を保存し、選手単位では以下も保持します。

- `line_id` : 第何ラインか
- `line_position` : ライン内の何番手か
- `line_size` : ライン人数
- `line_role` : 掲載されている役割情報

並び予想が公開されていない場合は推測しません。

## GitHub Actions

### S級予選 出走表収集

`.github/workflows/collect-s-yosen-2025.yml`

2025-01-01 から 2025-12-31 までを走査し、`Ｓ級予選` の出走表を取得・検証・保存します。

### ライン構成付与

`.github/workflows/enrich-s-yosen-lines-2025.yml`

出走表収集が正常終了した後、各レースの並び予想を取得し、ライン情報をデータセットへ付与します。

## シミュレーションで守ること

- レース結果・払戻は評価に使い、事前判断の入力へ混ぜない
- 判断時点で利用できなかった情報を使わない
- 欠損を推測補完しない
- 単発の結果だけで戦略ルールを変更しない
- 全体回収率だけでなく、レース種別・レース番号ごとの成績も分解する
- 利益が出る条件だけを結果後に選び直すデータスヌーピングを避ける

## 現在の研究範囲

現在は **2025年の競輪戦略シミュレーション**だけを扱います。

過去に検討した別系統の分析手法は、現在の戦略設計・データ収集・シミュレーションへ混ぜません。

## 目標

2025年の競輪データを再現可能な形で蓄積し、

**「どの種類のレースで、どのレース番号・構造・条件に、どの戦略を使うと収支がどうなるか」**

を機械的に検証できる基盤を作ること。

最終目標は、後付けではない一貫した戦略で2025年シミュレーションのプラス収支を目指すことです。
