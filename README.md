# keirin-market-analysis

競輪の**市場データだけ**を使って、3連複35通りと3連単210通りを全件比較・検証するための研究用リポジトリです。

## 固定方針

- 選手評価・展開予想・ライン評価・脚力・得点・級班などの非市場要素は使わない
- 3連複は7車立て35通りを全件対象
- D計算時は3連単210通りを全件対象
- 欠損値は推測で補完しない
- 取得時刻と取得元を必ず残す
- 結果後に指標定義や基準を変更しない
- 市場一致＝正しい、不一致＝価値あり、と短絡しない

## 現在実装している指標

### D指標

同じ3車集合について、

- 3連複市場での相対評価
- 3連単6順列を合成した相対評価

を比較します。

計算はオッズの逆数を各市場内で正規化し、

`D = 3連単6順列合成シェア / 3連複シェア`

とします。

- D = 1: 両市場の相対評価が一致
- D > 1: 3連単側が相対的に高く評価
- D < 1: 3連複側が相対的に高く評価

Dの高低だけで買い目判定はしません。35通り全件の順位と分布を見ます。

## C / H 指標

C・Hは候補として枠だけ用意しています。**現時点では数式を勝手に確定していません。**
定義が合意できた時点で実装します。

## 入力CSV

### 3連複

```csv
combination,odds,captured_at,source
1-2-3,5.4,2026-08-28T12:00:00+09:00,https://example.com
```

`combination` は昇順で `1-2-3` の形式です。

### 3連単

```csv
combination,odds,captured_at,source
1-2-3,12.8,2026-08-28T12:00:00+09:00,https://example.com
```

3連単は順序を保持します。

## 実行例

```bash
python -m keirin_market_analysis analyze \
  --trio data/trio.csv \
  --trifecta data/trifecta.csv \
  --out output/d_report.csv
```

不足があれば処理を止めます。35通り・210通りが揃っていない状態で分析結果を出しません。
