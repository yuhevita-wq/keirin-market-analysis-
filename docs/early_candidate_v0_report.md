# 2025 S級予選 前半 戦略候補V0

## 状態

探索候補。前半V1としては未固定。
中盤V0・後半V1は変更していない。

## 対象構造

- 2025年 完全一致「Ｓ級予選」
- 前半
- 本線3車以上
- 最強対抗ライン（2車以上）が存在

前半 × 本線3車以上は297R。
本線A+Bが1・2着を占めたのは106R（35.69%）。
中盤44.41%、後半55.81%より低く、前半は本線固定度が最も低い。

本線A+Bが1・2着でない191Rでは、上位3車のライン構成2+1が135R。
崩れ時の1着役割では最強対抗先頭R1Lが50Rで最多。

## 本線強条件の扱い

前半でも本線A+Bが1・2着になりやすい事前条件は確認できたが、対応する本線型フォーメーションの払戻評価はマイナス。
そのため「着順を読みやすい = 買うべき」とはせず、前半候補V0では本線型を購入しない。

## 前半候補V0

事前条件：

- 本線A+Bの勝率合計 <= 22.35

この閾値は2025上半期の「最強対抗R1L+R1Bが1・2着を占めるか」という構造ラベルの分岐から選定。
払戻は買い条件の選定に使用していない。

買い目：

1. R1L-R1B-A
2. R1L-R1B-B
3. R1B-R1L-A
4. R1B-R1L-B

各100円、1R400円。

A = 本線先頭
B = 本線番手
R1L = 最強対抗ライン先頭
R1B = 最強対抗ライン番手

## 構造安定性

条件該当時、最強対抗2車が1・2着を占めた割合：

- 上半期 9/40 = 22.50%
- 下半期 7/34 = 20.59%

上半期で作った分岐が下半期でもほぼ同水準で残った。

## 閾値感度

勝率合計条件を概ね20〜24付近へ動かしても、最強対抗2車の1・2着率は上半期・下半期で大きく崩れなかった。
22.35は上半期の構造分岐から得た値をそのまま使用し、払戻を見て後から調整していない。

## 注意

このルールは2025年内部探索から発見したもの。
上半期で構造条件を作り下半期で確認しているが、別年の完全なアウトオブサンプル検証ではない。
別年で固定ルールのまま検証するまでは前半V1へ昇格させない。
