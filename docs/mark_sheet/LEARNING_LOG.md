## 2026-10-11：2026年 寬仁親王牌（世界選手権）初日・2日目の敗因

### 0. 試験の目的と採点条件
- 出走表に基づきオッズを見ずに全レースの買い目・各金額を提出。
- 合格条件は開催日単位の最終収支プラス。的中率や「もっともらしい展開解説」は合格基準ではない。
- 安い的中で満足しないが、単純な穴狙い・点数増減・券種固定で解決したとみなさない。

### 1. 以前の会話の採点値（ここで独立再集計はしていない）

**検証上の注意：** 数値は直前の採点・敗因分析の会話から転記したもの。元答案・確定払戻と再照合できるまでは「前回採点に基づく」と区別して扱う。

### 2. 敗因の中心（現時点の仮説）
**選手の強さ・ライン序列から「自然で説明しやすい着順」に飛躍し、最初に置いた1着・2着の関係を固定制約にしてしまう。** 以後はその制約の下で3着候補や点数を増やすため、買い目数が多くても同じ仮説が崩れれば同時に外れる。

誤りの発生点は以下の通り。
1. 選手の能力・近況の評価を、そのまま最終着順の序列と混同する。
2. ある1着候補の勝ち方を限定しすぎ、同じ選手が勝つ別の2・3着の到達形を検討不足のまま排除する。
3. 複数点を追加しても、実際には同一の2着固定・頭固定など相関の強い失敗条件を共有している。
4. 採点後に「頭を増やす」「3着を広げる」「点数を減らす」「穴を足す」など直前の指摘へ反射し、選手・順序を消した事前根拠を再検証しない。
5. 過去問で高配当や筋違いの出現を知っていても、事前の候補選択・除外判断にその知識が接続されていない。

### 3. 今回の具体例（前回分析で挙げた照合対象）
| 日・R | 確定3連単 | 答案で検出された欠陥 |
|---|---|---|
| 初日7R | 3-1-8 | 1・2着候補を捉えても⑧を3着から除外 |
| 初日10R | 2-3-9 | ②頭を考慮しても③の2着を除外 |
| 初日11R | 3-8-1 | ③頭を考慮しても⑧の2着を除外 |
| 2日目3R | 5-2-9 | ⑤頭で⑨2着に固着し、⑨3着＋②2着を落とした |
| 2日目6R | 5-1-2 | ⑤頭を買いながら①2着を落とした |
| 2日目12R | 8-2-3 | ⑧頭・③の3着内を落とした |

2日目12Rでは②古性－⑧荒井という事前の並び、前日の荒井の好走があったにもかかわらず、荒井の差しによる⑧頭を答案の検討対象から外していた可能性がある。これは「結果を知ったら買えたはず」という後知恵と混同しない。事前材料が十分だったかを、元答案・出走表・当日近況だけで再評価する。

### 4. 反省の誤用をしない
- 上記を根拠に「頭固定禁止」「2着固定禁止」「異線必須」「毎レース穴を購入」「必ず特定点数を買う」などを**新設しない**。
- 高配当の未的中をすべて同列に扱わない。事前の材料が乏しい大波乱と、事前に検討し得た選手・位置の見落としを区別する。
- 競輪の結末は脚力、位置、コース、車間、スピード、前後の関係から生じる。役割名やライン順を着順に機械的に投影しない。
- 反省文が上手く書けたことを学習の成功としない。**合格を達成する答案の改善**が必要。

### 5. 次回からの検証課題（固定購入ルールではない）
- 各レースで最終的に除外した上位入線候補・組み合わせについて、出走表時点の根拠があったか検査する。
- 外れを少なくとも「3着内の選手自体を消した」「選手はいたが着順が違う」「一つの着順拘束で複数点が同時に失敗」「偶発的な事故等」「収益設計の不備」に分離して数える。
- 特に「1着候補が正しくても2着を固定して失敗」の頻度と資金損失を測る。改善は単に2着候補数を増やすことではなく、勝ち方と他選手の到達可能性の再評価で判定する。
- 過去の同大会の高配当決着について、**結果を隠した出走表から同じ発見ができるか**を調べる。別年・別開催での未使用レースで再検証し、後付けの買い足しを改善と認めない。
- 最終評価は一日の収支、および複数開催を通じた回収率・損失分布。的中率だけで採点しない。

### 6. 結論の一文
> 「当たると思った理由」ばかり考え、「外れると判断した理由」の正しさを検証していなかった。

これは**現在の分析仮説**であり、次の実戦答案と採点で妥当性を検証する。作ったマークシートが綺麗に見えることを、競輪の現実への適合と混同しない。

## 2026-10-11：2021年3日目のA高配当的中は「何を当てた」のか

### 事実
- 2021-10-23 弥彦・寬仁親王牌3日目11R、Aは`3-8-5,1,9,2,4,7`を含む計18点（1,800円）を購入。`3-8-7`が的中し、3連単58,270円を回収。
- ③新山響平が逃げ切り、⑧大槻寛徳がマーク2着、⑦山田庸平は別線から切り替え3着。
- 大会前のレース評では⑤郡司浩平と⑨古性優作が高く評価されたが、両者は着外。③⑧のライン決着自体は競輪として自然でも、市場全体では本命視されていない組合せだった（3-8の2車単払戻5,050円）。
- Aは1着③・2着⑧を含む**強い条件付け（決着ペア）**を正しく選んだ。他方、③⑧の後ろの3着候補には残り7人のうち6人を入れており、⑦山田だけを特別に精密予測したわけではない。
- この日のAは11R以外の払戻が9R1,710円＋12R5,990円＝7,700円。11Rの1発がなければ、Aの同じ総投資19,500円に対する払戻7,700円で**収支-11,800円**だった。この日の合格は1つの高配当的中に大きく依存。

### どこが「常識」で、なぜ高配当か
- Aを「安配当・人気順の予想」と呼ぶのは不正確。実態は、強力な自力選手と番手など**自然なペアを複数組み、3着を広く流す**答案。
- 競輪のライン上自然な決着と、多数の投票者が高評価する決着は一致しない。今回の③-⑧はその例。
- ゆえに「既存の常識でも高配当を取れる」は事実だが、「正確に3着まで当てる技術が向上した」「ライン決着中心にすれば儲かる」は**示されていない**。

### 3つの評価を混同しない
1. **的中**＝実際に購入券が成立したか。これ自体は損益を保証しない。
2. **予想の正誤・論理の妥当性**＝事前の証拠に基づいて着順条件と候補の選別が支持されるか。結果を見た後の説明や、的中1回だけでは妥当性の証明にならない。
3. **収益**＝1日総収支。マークシート試験の合格基準はここにある。妥当な予測判断は収益を目指すための手段であり、説明の美しさは目的ではない。

### 学習上の注意
- 11Rの収益貢献を肯定しつつ、③⑧の選択力と⑦を広く流して拾った効果を別々に記録する。
- 的中率を上げるために安い目を大量に買うことも、正しそうな理論を守るために収益機会を捨てることも目的に反する。
- この例だけから「3着は常に6人」「常識的ラインでも穴になるから常に3ラインの頭+番手固定」といった購入ルールは新設しない。
- **目的は検証可能な判断を用いて未来の1日総収支プラスを目指すこと。** 過去問の合格・不合格は結果で採点し、将来に再現できるかは別途未使用データで検証する。
