# 第1章：精度AI vs 校正AI 対戦記録（2024年1〜6月）

## 同一条件・事前固定

- 精度モデル：acc-g08-c01（2023年1〜8月学習、10月精度で選抜）
- 校正モデル：g01-c01（2023年1〜8月学習、9月温度補正、10月ECEで選抜）
- 3連単2/3着の条件付きモデルは両者ともg01-c01で固定。差分は1着モデル。
- 同一4,521レース。Q1は3,294レース、Q2は1,227レース。
- 券種は3連単・3連複、全買い目について推定確率×確定オッズ > 1で1点100円を購入。
- 各モデルが事前選抜済みで、2024年のデータからfit、選抜、閾値変更を行わない。

## 限界と研究結論

- 2024年Q1/Q2は他のプロジェクト研究で既に参照済みで、プロジェクト全体の純粋な未知データではない。
- Q1の出走表カード5,443のうち3,294レース（60.5%）、Q2の5,570のうち1,227レース（22.0%）のみが完全なLINE/結果/全券種オッズと照合できた。欠損による母集団の偏りに注意。
- 誤差の校正分岐は既存の条件付き20bin ECE代理指標。原論文の二値分類条件の完全再現ではない。
- 3連単と3連複では払い戻しに相関があり、同時1/8ケリーの計算は参考値。
- 確定オッズであり締切15分前の購入価格とは限らない。
- 精度AIが回収率で僅差勝利したが不確実性は大きく、**両AIとも利益が出せていない**。2024年結果を使った閾値調整は不可。次は新しい設計と改めて固定した時系列で研究すべき。
