# 第1章：終了したレースで利益を確認したモデル（研究用）

出力：report_2023.json

モデル名：2023年の全券種オッズ＋LINE・競走得点・年齢等を用いた非線形な価格誤差学習AI。
2023年1～8月の実際の結果・市場確率を教師データとし、全3連単・3連複から、推定期待値が正の買い目を選ぶ。

## 固定した実験の時系列

- 学習：2023年1～8月、4,769レース、3連単962,046サンプル＋3連複160,341サンプル
- 市場との確率統合の比較：2023年9月361レース
- 購入ルール・係数の選択：2023年10月441レース
- **購入ルールを固定した後の歴史検証**：2023年11～12月857レース
- 賭金：選ばれた3連単・3連複の各買い目100円、モデル確率×実確定オッズ > 1.05
- 選択した確率：モデル単独重み（AI指数1.0）、購入の期待利益要求は5%以上

## 再現した収支

| 月 | 購入点数 | 回収率 |
|---|---:|---:|
| 2023年10月（ルール選択対象） | 3,180 | 117.04% |
| 2023年11月 | 3,757 | 228.93% |
| 2023年12月 | 4,919 | 89.09% |
| 11～12月合計 | 8,676 | 149.65% |

2023年11～12月の投資867,600円、払戻1,298,340円、差額**+430,740円**、的中56点。

**判定：2023年11～12月合算で収益プラスのAIの構築に成功。ただし12月単月赤字であり、両月プラスの厳格なゲートは未達。**

## 研究上の注意

1. 2023年11～12月は、このプロジェクトの以前のLINEモデル研究で参照済みであり、完全な初見検証ではない。
2. 10月は候補選別のため実際の回収率を参照している。10月の117%は独立成績ではない。
3. 11月の大きな払戻が合計収益を押し上げており、再現可能な優位性とはまだ言えない。
4. 計算は確定オッズで行われ、締切15分前に同じ価格で買えるとは限らない。
5. 勝ち逃げや任意の点数制限ではなく、各レースで全券種組合せの確率を算出する。
6. モデルと成績はGitHub Release chapter1-market-boost-research-2023-v1 に凍結保存済み。現行本番の第1章自律RFを、この研究モデルで置き換えたわけではない。

現段階の正式分類：HISTORICAL_COMBINED_ROI_POSITIVE / MONTHLY_STABILITY_UNPROVEN / LIVE_EDGE_UNPROVEN

## 次に必要な研究

まず月ごとの回収率が不安定な理由を、価格帯・人気帯・レース種別・ライン関係別の実結果で分析する。2023年11～12月の結果を見て事後的に買い目を除去してはならない。次のモデルの調整は独立した学習期間から実施し、2024年以降の既知の検証結果にも適合させない。
