# 競輪AI研究 第1章：自律学習エンジン

対象論文：Walsh & Joshi — Machine learning for sports betting: should model selection be based on accuracy or calibration?

## ミッション

研究をChatGPTが手で進めるのではなく、GitHub上の競輪AIが新しいモデルを生成し、学習・確率校正・2つの評価基準による選別・モデル重み保存を繰り返す。論文の中心的な問いは「確率校正基準のモデル選択が、的中精度基準の選択より収益性を高めるか」である。

全ての成功と失敗を記録する。損失を隠したり、過去の結果に合わせて同じ期間を再調整してはならない。

## v1の設計

- 凍結された元モデル：2023年全期間のLINEあり3段階RF、20,349レース。GitHub Releaseの重みを毎回SHA256確認。元モデルに上書きしない。
- 学習：2023年1月～8月。候補のRF/LR、パラメータ、選手特徴量を各世代AIが自動的に変更する。
- 温度校正：2023年9月のみ。
- 開発モデル選択：2023年10月のみ。「条件付き1位精度」と「条件付き20bin ECE」の2系統で独立にチャンピオンを選ぶ。
- 禁止：2023年11～12月と2024年以降の結果・オッズを、この候補選択に用いない。既知2024 Q1/Q2のROIに調整を合わせない。
- 20binの80％非空制約を条件付き確率の代理指標として測定。原論文の2値クラス／3連単・3連複全組合せ確率校正と完全に同等とはみなさない。
- 週次のGitHub Actionsが1世代進める。昇格したモデル重みはGitHub Releases、探索履歴はstate.jsonに保存する。
- 固定された同じ開発データへの探索を無制限に続けない。24世代で新しい独立データ・新しい実験設計を必要とする安全停止に移行する。

## 本当の第1章の到達に向けて今後必要

現行v1は自律的な候補生成・学習・校正・保存の開始段階。原論文の研究目的を達成したと認定するには、次の別工程が必要。

1. 最終的な3連単・3連複の全買い目確率を計算し、確率校正と的中精度を厳格に評価する。
2. 開発時に結果を参照していない未来の独立期間を一度だけ評価する。
3. 両モデルを同じレース・同じ確定オッズ・同じ資金配分規則で比較し、回収率・市場との確率差・欠損率を測定する。
4. 期間外の評価結果から同じ期間に再調整することを禁止する。
5. 厳格なデータ分離で検証が完了するまで、論文に到達したと主張しない。

この時点でAIはまだ「研究するAIの初期実装」であり、完成した収益モデルではない。投票は一切しない。
