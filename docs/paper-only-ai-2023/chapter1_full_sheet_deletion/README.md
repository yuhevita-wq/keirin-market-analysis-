# 第1章：全面記入から削るAIの検証

## 目的

精度重視AI（acc-g08-c01）と校正重視AI（g01-c01）の双方に、**最初から3連単・3連複の全組み合わせに印をつけ、削除するほどコストが改善するか学ぶモデル**を追加した。

購入点数やフォーメーションを最初から決めない。レースの結果を見てから未来レースの削除を組み立てることはしない。

### 処理と学習

1. 全3連単・全3連複を100円ずつ購入対象にしたマークシートを作成。
2. 出走前に利用できる選手情報、公開予想LINE、確定オッズと保存済みAIの確率から、1点ずつ削除の危険度を計算。
3. 2023年9月の確定結果を教師として、削除した場合に失う当たり払戻額を考慮した非線形分類器4本を独立学習。高額払戻の影響による学習暴走を抑えるため、教師の陽性重みのみ250倍で打ち切る。実際の払戻採点は打ち切らない。
4. 10月の結果だけで「残すモデル確率質量」の境界を選択。**残す点数は先に決めず、消した結果として残存点数が決まる。**
5. 11月・12月には凍結済みルールのみ適用。消した当たり車券は払戻全額を失った扱いにする。

9月は元の校正AIの温度校正にも使用、10月は元の的中精度AIの選択にも使用、11～12月は過去の別研究で参照済み。完全に初見の独立検証とは称しない。今回の使用オッズは最終確定オッズであり締切15分前の価格ではない。

## 学習・選抜結果

- 確認用の完全なレース：2023年9月361R、10月441R、11月428R、12月429R
- 2023年10月の開発期間で選ばれた確率質量の残し方：精度AI35%、校正AI50%
- 2023年11～12月：共通857レース

| 指標 | 精度重視＋削除AI | 校正重視＋削除AI |
|---|---:|---:|
| 全購入のマーク数 | 206,633 | 206,633 |
| 消したマーク数 | 184,771 | 167,924 |
| 残したマーク数 | 21,862 | 38,709 |
| 残存当たり車券数（最大1714） | 659 | 1057 |
| 削除前回収率 | 74.62% | 74.62% |
| **削除後回収率** | **73.35%** | **73.09%** |
| 削除後投資額 | 2,186,200円 | 3,870,900円 |
| 削除後払戻額 | 1,603,630円 | 2,829,250円 |
| 削除後の純収支 | **−582,570円** | **−1,041,650円** |
| 全面購入と比べた赤字削減 | ＋4,661,650円 | ＋4,202,570円 |

精度AI側の月別回収率：11月76.38%、12月70.47%。校正AI側：11月71.21%、12月74.87%。

### 正式判定

**削除の利益は赤字削減にとどまり、回収率を改善できなかった。研究として実行済み、不合格。**

全マーク購入のコストを何百万円も減らすことは難しくない。それだけを「市場の誤りの発見」としてはいけない。重要なのは消した当たり券の機会損失を上回り、残した組合せの払戻収支がプラスになること。

## 今後の改善軸

- 同じ残存点数のランダム削除・低オッズ順削除に対する対照実験を実行して、削除順位そのものの優位性を調べる
- 比較条件を事前固定し、次の期間は過去検証結果に合わせ込まずモデル設計を独立に再構築する
- 利益回収率100%未満の場合、モデルが大量の印を消しても合格認定しない
- 確率の高い券を残すことと、期待払戻が高い券を残すことは異なるので、どの基準の削除が市場誤差を捉えるか定量検証する

## 追加：同じ残存点数による削除効果の切り分け（11～12月）

削除による投資削減だけでは改善したと判断できないため、元のモデルを変更せず、全く同じ月・レース・券種で、**削除した点数の数だけを揃えた**対照実験を実施した。

| 3連単＋3連複の回収率 | 精度重視モデル＋削除 | 校正重視モデル＋削除 |
|---|---:|---:|
| 学習した削除順位 | **73.35%** | **73.09%** |
| 同数の一様ランダム削除（払戻期待値） | 73.44% | 74.60% |
| 同数の安いオッズ優先 | 72.52% | 72.08% |

**重要：学習した削除順位は合算でランダム削除期待値を下回った。** 3連単の精度AI側のみランダム期待値を若干上回ったが、3連複は両モデルともランダム期待値および安いオッズ順より低い。この段階で「市場優位を発見した」とは言えない。

この統制実験は過去の評価結果を使ってモデル・購入ルールを変更するものではなく、既に選ばれた削除器と削除強度を凍結したまま実行した診断である。ランダム側は毎レース・各券種で同じ点数を残す一様ランダム抽出の数学的期待払戻を使用し、実際のランダム抽選実現値ではない。

## 次の研究に向けた制約

1. 不合格だった同じ11～12月結果から削除係数や閾値を選び直さない
2. 3連複の誤削除コストを独立に分析し、次の訓練期間でのみ設計・再学習する
3. 改善後も「同じ残存点数のランダム削除」と「安いオッズ順」の両対照を必ず評価する
4. 収益黒字（回収率100%超）と、削減投資による赤字縮小を混同しない
