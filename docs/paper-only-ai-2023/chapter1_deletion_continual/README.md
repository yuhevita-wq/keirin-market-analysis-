# 第1章：全マーク削除の継続学習（2024年）

## 開始点

前回の単発削除AIは2023年11〜12月の回収率が精度重視系73.35%、校正重視系73.09%で、同じ残存点数のランダム削除期待値にも届かなかった。今回の実験は**その削除モデルを訓練の開始状態にし、過去の終了したレースを順番に学習する**。

親AIは精度重視acc-g08-c01と確率校正重視g01-c01。2023年学習済みの削除器4本をSHA256で照合して凍結し、修正しない。今回の新しいオンライン補正係数4本だけをレースごとに更新する。

## 1レースの学習工程

1. 実際に存在する全3連単・3連複を初めにマーク。1点100円のフルシートを作る。
2. 出走前の選手データ・LINE・オッズと凍結した親AI確率、旧削除器のスコアを入力。
3. 削除によって失う予測期待払戻が小さい印を1点ずつ消す。最初から券種の優先順位、残す点数、フォーメーションを固定しない。
4. 2023年10月に決めた残存確率質量の制約は精度重視系0.35、校正重視系0.50で凍結。2024年の結果を見て変更しない。
5. すべての判断が出た後、実際の結果を公開。消した印が外れなら100円節約、消した印が当たりなら実払戻全額を機会損失として計算する。
6. 実結果を使って条件付き確率のオンライン補正係数を更新。勾配を制限し、次のレースへ進む。

モデル4本は精度重視×3連単、精度重視×3連複、校正重視×3連単、校正重視×3連複。

## 時系列と保存

- 2024年第1四半期から順番にQ2、Q3、Q4と進む。GitHub Actionsの1回の実行で、次の四半期を1つだけ実行。
- 各四半期終了時、重み4本・出典・処理済み期間・収益・削除枚数・削除した当たり券数をGitHubに保存する。
- 期間内の各レースについて意思決定は結果を使わず、そのレースの結果が確定してから次レース向けに更新する。
- 2024年は過去の別研究で既に参照した歴史期間なので、時系列で予測していてもプロジェクト全体として完全初見のテストではない。2024年の学習を終えた後に、2024年を独立テストと称することは不可。
- 2024年4四半期を全て学習したら学習は安全停止する。2025年以降を訓練に使うかどうかは、別の時系列試験設計で決める。

## 同じ残存点数による比較

各券種・各レースで、学習削除AI、凍結2023旧削除AI、同数ランダム削除の理論期待値、同数の低オッズ順残存、全マーク購入を並べる。

当たり券を消して失う払戻を無視した見かけの赤字削減は不合格。回収率100%超かつ同数残存の単純削除法への優位性を、独立した別期間で再現できることが最終目標。

使用オッズは確定オッズ。締切前に同じ価格で購入できるとは限らない。実際の車券購入は実施しない。
