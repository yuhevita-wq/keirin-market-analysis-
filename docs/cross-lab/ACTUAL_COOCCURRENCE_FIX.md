# CROSS LAB — 個人能力だけの配列から「同時入着の実結果学習」へ

2026-10-17。ユーザー指摘「強い選手を並べても、その2人が同時に入着できる根拠ではない」を実装・検証ルールにした。

## 実装上の絶対規則

1. 得点、B、決まり手、単独勝率や3連対率の大小そのものを、2選手の同時成立の根拠として表示しない。
2. **別の教師ラベル**として (a) 2人が1・2着を占める（表裏両方） (b) 2人とも3着以内を作る。両者を「同時入着」という言葉で混ぜない。
3. 強強、強弱、筋を優劣判定する前に、実際のレース結果を教師とし、同時成立に関する競合・共存の条件を学習する。
4. 学習モデルを出すときは、同じ学習・検証対象の**選手能力のみの対照モデル**も必ず出す。共存モデルの高い数字だけでは機構の発見と呼ばない。
5. データ期間を時系列で分離し、将来年で順位精度・確率損失を検証する。予測値に「実測的中率」と誤表記しない。
6. 特定ペアの順位が高くても**クロス4点を自動採用しない**。3着指定の条件付き確率は独立の別学習課題とし、未学習なら「4点未判定」と記す。
7. 1つのペアが成立しにくいことから、別の強弱ペアが成立すると**補完しない**。別ペアは個別に予測する。
8. 具体的な実測・学習モデルなしに「別線から進出できる」「市場が支持」「決まり手が強い」といった作文で補完して順位を付けることを禁止。

## 9車・S級G1/G2/G3の完成した比較

- 教師データ: `data/grade_races` の出走表と**確定着順**。学習用コード: [train.py](../../research/cross_pair_coexistence9/train.py)
- 2022–2024: 3,089Rで学習。
- 2025: 2,201Rで後続検証。
- 2026上半期: 941Rで独立後続検証。
- ペアの同時1・2着 (36通りから最高1組) の的中: 2025年 19.35% → 28.40%、2026上半期25.50% → 31.03%。
- ペアの同時3着以内 (36通りから最高1組) の的中: 2025年34.71% → 41.16%、2026上半期38.58% → 41.66%。
- 損失 (top2レース対数損失、top3ペア対数損失) とも2期で改善。
- 完全な観測指標、学習・検証分離と失敗時の制御: [validation.json](../../research/cross_pair_coexistence9/validation.json)。
- 画面コードは `coexistence9.mjs`、学習済み係数は `coexistence9_frozen.json`。個人能力モデルとの差（pp）を全異線ペアで見せる。
- **9車4点選定と回収率の成功は未証明**。学習モデル本体にも `canAutoRankCross4:false` を固定。
- PythonとブラウザJSの特徴量・全36ペア確率の実レース一致は [test workflow](../../.github/workflows/test-cross-lab9.yml) で検査。

## 7車の扱い

7車の既存v5.2には相互作用モデルと後続検証が存在するが、同時成立条件の因果的確定・安定回収率改善までは実証していない。
7車モデルの未実証部分を9車へ流用しない。9車の実結果ペア学習を、7車での回収率優位の証拠にも転用しない。

## 未完了の研究

- 9車の各方向の条件付き2着競合と、**2人が1・2着になった条件下で誰が3着に残るか**を実結果から別学習すること。
- 3車ライン全滅の条件付き頻度を学習し、候補4点の見落としを抑えること。
- 4点的中率・回収率を2025/2026の凍結条件で別検証すること。これが終わるまで、9車4点の順位を確定的と呼ばない。
