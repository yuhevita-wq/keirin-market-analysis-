# CROSS LAB v2 — 全型比較と採用記録

公開先: https://yuhevita-wq.github.io/keirin-market-analysis-/cross-lab/

## 基本4点

異なる2ラインの先頭・番手4車を選び、異線2車の1・2着表裏×残り2車の3着。1ラインペアにつき先頭×先頭・先頭×番手・番手×先頭・番手×番手の全4型を列挙する。役割や決まり手0だけで型を削除しない。決まり手の実数と成立仮説・反証を表示するが、件数を確率や優位性に変換しない。

3車ラインの番手が1・2着なら同線3番手を（）補助表示。2車ライン同士なら選外3車ラインから1車を既存の根拠照合で（）補助表示。補助は基本4点に混ぜない。横棒の筋も参考表示する。

## 検証用の自動市場モデル

既存の `data/models/market_probability_v1_s_f1_2025.json` を係数変更なしで接続。2023～2025年までのS級市場補正モデルをJavaScriptへ移植し、210着順の同時確率をクロス4点単位に集計する。手入力だけの版に置き換えない。

対象はS級F1・5～7車。開催区分、各選手の得点・年齢・勝率・3連対率・脚質・B・逃捲差マ、および3連単と3連複の全オッズが必要。欠損を0で埋めず、A級等に係数を転用しない。入力が揃えば検証用モデル基準で主採用1型を明記する。基本4点の等額期待回収を比較するが、利益が証明された自動購入機能ではない。

既存の時系列評価は2025年5,061R・2026上半期2,523R。予測誤差は市場より改善した一方、2026上半期の既存1点選別は利益が安定していない。クロス4点としての選定成績は別途時系列検証が必要。学習時の確定オッズと現在入力オッズの時点を混同しない。確定オッズによる検証は可能だが、結果を予測入力には使わない。

Pythonの既存特徴変換とJS移植を同じ合成出走表・210着順で照合。係数を今日の別府結果に合わせて変更していない。

## 採用方法

候補の先頭を自動主採用にしない。出走表を取り込み、全型を比較する。

1. 分析者判断: 採用クロス・異線同時残存の理由・別クロスとの比較・筋との比較・選外車への反証を入力する。主採用1型を明記し、判断内容をJSON保存できる。理由の入力をAIの独立検証と偽らない。
2. 別モデルの数値: 全着順の同時確率と全候補4点のオッズを入力した場合、等額期待回収で1型を比較する。同値や価格欠損では車番順で選ばない。入力モデルの較正・収益性を保証しない。

判断材料が不足する場合は「主採用未決定」と明記する。無根拠に最良と称する自動選定は行わない。利益優位のある最良クロスを自動選定できることは未実証。

予測JSON形式:

```json
{"raceId":"8620261014010006","source":{"id":"YOUR_MODEL","trainThrough":"2025-12-31"},"probabilities":{"1-2-3":0.01}}
```

上記は形だけの例。実際には当該レース全着順（7車なら210点）が必要で、合計1にする。レースIDが一致し、学習終了日は当日より前であることを検査する。確定結果や払戻は予測入力に使わない。

4点等額の期待回収倍率は `sum(p_i * odds_i)/4`。合成オッズ・逆オッズ正規化と混同しない。オッズだけから購入優位や的中確率を作らない。基本クロス・1/2着同線・3ライン・基本役割外の全確率質量も比較表示する。

## データ取得

楽天Kドリームスのracedetail URLからリポジトリの既存キャッシュを読む。未収録URLの外部スクレイピングは行わず手入力へ切り替える。B・逃・捲・差・マを入力でき、欠損は0としない。オッズは任意入力。
