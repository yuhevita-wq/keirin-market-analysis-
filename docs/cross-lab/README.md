# CROSS LAB – 異線成立条件判定 (cross-interaction-v1)

## なぜ作り直したか

従来の「競走得点・Bが高い選手を並べる → クロスの形に整形する」は、クロス成立条件を予測していない。この実装ではその処理を禁止する。

## クロス4点は変更しない

選ぶのは異なる2ラインの各2車。1着・2着は各線1名ずつ（表裏）、3着は選んだ残りの2車。例：`13-13-24` = `1-3-2 / 1-3-4 / 3-1-2 / 3-1-4`。

- 最初から3着を独立のランキングで決めない。
- 同じラインの2選手を1/2着クロスとして選ばない。
- 3–2–2の2車×2車クロスでは、基本4点に限り選外3車ラインの全滅条件を表示（（）付き3着補助では緩和）。
- 補助の3着は（）付きで明確に区別し、基本4点に無断で混ぜない。必要に応じて表裏2点を補助として別表示する。

## 選択基準

【成立条件を持つ異線の1/2着組だけを候補化】。実装したメカニズムは：
1. 一線の先行実績（Bと逃げ）×他線の捲り実績
2. 一線の先行からの番手差し×他線の捲り
3. 一線の先行×他線捲りの番手差し

さらに選外3車を個別に検査し、強い競合・3車ライン全滅・他ライン全滅という反証を付ける。得点はUIの選定に一切使用しない。Bだけでも発火しない。弱い決まり手も0とみなさず1件から検査する。

**重要：** 上記は物理的に成り立ち得る構図の限定的な仮説であって、過去結果から較正済みの勝率モデルではない。候補が複数あっても**主採用1組を明記**するが、同評価・未取得データ・強い反証が残る場合は**暫定**として示す。暫定選定は的中確率や期待値の優位を意味しない。回収率や利益優位性についてはまだ判定しない。

## 主採用と3着補助の仕様（2026-10-14）

- 全候補は比較用として残すが、最上位の成立条件・選外反証条件を持つ候補を**主採用**と明示。同評価なら順位は仮置きと記録し、強い選手順・レース得点・B単独で無理に選ばない。
- 3車ラインの番手がクロスの1着/2着候補に入れば、同ラインの**3番手**を3着補助として**（車番）**で表示。基本4点の3着に既に含まれていれば重複加算しない。
- 2車ライン同士のクロスで選外にちょうど1本の3車ラインがあれば、そのラインの**1人**を3着補助として**（車番）**で表示。逃げ/B・捲り・差し・マークの具体的な3着流入根拠を検査し、必ずしも番手を選ばない。根拠が不足した場合は空欄にして「根拠不足」と示す。
- 追加分は両表裏の2点を**補助**として別表示。基本4点と合算して勝手に「6点推奨」にしない。オッズが未取得なら高配当と断言しない。

## 出走表と取得できる情報

`index.html` は楽天Kドリームスの `/racedetail/{race_id}` を受け取り、リポジトリ内 `docs/keirin-shogi/live-race-data.json` のキャッシュを参照する。対象外URLを外部スクレイピングできると偽らない。キャッシュ未収録なら手入力に切り替える。

読み取った並びを入力で修正可能。選手ごとに逃・捲・差・マの値を入力可能。空欄は**欠損**、0ではない。出走表に決まり手が入っていなければ自動推奨しない。

3連単オッズは任意入力。入力されれば参考表示のみ。オッズがなければ市場評価不可。逆オッズ正規化やライン別の過去確率を個々のクロス4点の的中確率として転用しない。

## 起動とテスト

- GitHub Pages 上の `docs/cross-lab/index.html`（Pages側で`docs`公開が設定されている場合）
- エンジン: `cross_engine.mjs` / 主採用・補助表示: `cross_presentation.mjs`
- テスト: `node --test docs/cross-lab/*.test.mjs`
- ブラウザーから必要なのは `index.html` と同ディレクトリの `cross_engine.mjs`、`cross_presentation.mjs`、`horizontal_line_reference.mjs`、既存のキャッシュ。
