## 定義（復旧）
異なる2ラインの**先頭・番手2人ずつ**の計4人から、1・2着を異線の1人ずつ表裏、3着は残る2人とする**3連単4点**を生成する。
3–2–2ではライン組が3つ×各4型＝**計12型**（1型4点）。3車ラインの3番手は基本4点へ混ぜない。3車番手が1・2着候補なら（）の3着補助、2車×2車なら選外3車ラインから根拠のある1車を（）補助として別表示。横棒の筋は参考表示。

## 選定（復旧）
データが揃ったA級1・2班／S級7車は、学習済み同時入着v3を**初期状態で有効**にする。単独で「どちらかが勝つ」のではなく、異線2車が表裏で1・2着になり残る2車が3着となる**4点の同時確率の合計**を比較する。
- 全候補の3連単オッズが揃っている場合は**4点等額の推定期待回収**で比較する。
- 全候補のオッズが不足する場合は**4点の推定的中確率**に切り替える。この場合、割安・高配当・利益優位とは呼ばない。
- 唯一の順位1位が存在すれば**主採用（モデル暫定1位）**を明記し、全候補をそのモデル順位で表示する。自動主採用・採用根拠・補助は答案として保存し、結果と照合する。
- 同率1位／学習済みモデルの入力欠損／対象外級・車数の場合は判定不能を表示する。得点順・車番順・根拠件数で勝手に穴埋めしない。
- 分析者による採用理由付きの手動上書きは維持する。

**限界：** 同時入着v3の過去回収率で安定的な利益優位は実証されていない。順位1位はモデル内の相対的判断であり、レース結果を知っていることや展開の因果を証明しない。選定・採点の入力に当日結果を使用しない。

## 判断の計算

1. 同じレースの全42通りの順序付き1・2着を一括で正規化する。個々の勝率を掛け合わせない。
2. その1・2着が成立した条件で、残り5車の3着確率を計算する。
3. 全210着順を合計1にし、筋・基本クロス・3ライン・基本役割外を同じ分布で比較する。
4. 全クロス型の基本4点確率を合算して比較順位を表示する。順位1位を自動的に主採用へ変換しない。的中確率順位と期待回収順位はUIで明示的に選び分ける。期待回収は全候補の4点オッズが揃うときだけ比較する。
5. 各順序に「Aが1着のときBが2着」「A-Bが1・2着になる確率」「その条件で残る2車が3着」を表示する。表裏を同率とはしない。

個人の得点・勝率・3連対率・決まり手に加え、両先頭のB/逃げの競合、先頭の負荷と番手、別線先頭の圧力、差し・追走の組合せを学習する。係数の符号や役割による有利不利を手で固定していない。全番手型も残し、番手優遇や先頭同士の無条件禁止にしない。

## 定義・補助

基本は異なる2ラインの先頭・番手4車。各ラインペアの全4型を比較し、1・2着表裏×残る2車の3着＝4点。基本4点の3着を別の選手で作り直さない。3車ライン番手が1・2着なら同線3番手を（）補助、2車ライン同士なら選外3車ラインから1車を既存の根拠照合で（）補助。横棒のライン筋は補助表示であり、クロスへ混ぜない。補助選定ロジック自体は今回は変更していない。
