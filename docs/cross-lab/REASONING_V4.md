# クロスLABO v4：答えを導く根拠の改訂

2026-10-15。クロスの定義・基本4点・横棒補助・括弧補助を維持する。

## 撤去した誤り

- B≧2、逃げ≧1、捲り≧1等の組合せを「同時残存の裏付け」にしていた。別々の実績は今回同時に起こる証拠ではない。
- 条件に該当しない候補を「根拠未成立」と扱っていた。観測できないことと起こらないことを混同していた。
- 補助3着を決まり手の該当項目数で選んでいた。件数は今回その位置を取れる根拠ではない。
- 「選外3車ライン全滅が必要」という着順の定義から、当該レースの起こりにくさを断定していた。

## 分析者が答えを導く順序

1. 全員の材料を確認する。得点・B・決まり手は捨てない。ただし、その数字がどの相手・位置・競走条件から生じたかを確認する。条件が不明なら不明とする。
2. 二線の各クロスについて表裏を分ける。Aが勝つ動きのとき、Bは何をして2着に残るのか。Bが勝つ側も別に考える。Aの勝因がBの残存条件を壊すなら、その矛盾を記す。「どちらかが勝つ」を「二人で1・2着」としない。
3. 同じ材料で筋決着・別クロス・選外の侵入も説明する。選んだ型だけに都合のよい仮定を与えない。2着を争う他の5人を比較する。筋は比較・補助であり主クロスにすり替えない。
4. 事実→今回に当てはまる条件→表裏別の推論→反対材料→未確認事項を短く残し、相対的に選ぶ理由を明記する。全条件の証明を要求して思考を止める運用にしない。未知をゼロや否定に置き換えない。
5. 基本3着は選んだ4人の残り2人。再選抜しない。2車×2車の括弧補助は選外3車ラインの1人を今回の関係で選び、理由を付ける。番手自動選抜・件数選抜をしない。
6. 採用時点の入力と理由を保存する。採点では、観測事実の誤り／条件の適用違い／表裏の両立の誤り／他候補との比較の誤りを分ける。一度外れた型を一律禁止しない。

例（考え方の説明であり実レースの事実ではない）：
「差し3回だから番手が残る」は根拠にしない。「前が踏み直した場面で追走できた」という観測があるなら、当時の相手・速度・位置と今回の違いを検討する。今回も追走できるという部分は推論として書く。観測がなければ作らない。

## 実装範囲と限界

- `cross_engine.mjs` は数値閾値の支持／否定を廃止し、全合法型に表裏別の相手比較を生成する。集計値の増減で質問・候補・支持状態は変わらない。
- `cross_comparison.mjs` は分析者判断を事実・出典と条件・表裏別推論・反対材料・不確実性に分離して返す。空欄は未記録。文章が埋まったことを真実の証明とはしない。
- 画面は上記を記録・表示・JSON保存する。集計値からの学習モデルは任意の補助比較として残すが既定でオフ。モデル係数は変更していない。
- 2車×2車の補助は明示された1車と理由を使う。分析者がまだ選んでいない場合は未選定と表示し、数字で穴埋めしない。
- 映像・個別走行履歴を自動取得して推論する機能や、新しい学習済み予測器を実装したものではない。現時点で公開画面が自動的に最善の答えを出せるとは言えない。性能向上・回収率向上も未検証。
