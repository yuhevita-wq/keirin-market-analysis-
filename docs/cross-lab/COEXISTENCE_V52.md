# CROSS LAB v5.2 — 強強・強弱の同時成立判定

2026-10-17。ラインの強弱と選手の強弱の両方を対象とする。個々に勝てることと、2人で1・2着になることを分ける。主採用は新しい同時確率から基本4点を集計して順位付けする。

## 今回の結論

- 共存予測の平均対数損失はA級・S級とも2025年／2026年上半期で改善した。ただし基本4点・回収率の安定改善は未達成。
- 今回は旧線形モデルから木モデルを追加した比較であり、強強・強弱の特徴だけの効果を分離した証明ではない。条件の因果説明や確定的な非成立は未解明。
- 強強より強弱の1・2着確率が高いだけで強強を強制除外する条件は、後続評価で安定改善しなかったため通常選定では無効。無効な切替を成功と報告しない。
- 「同時成立しない条件」を確定できたという結論ではない。強強／強弱／筋を比較し、3着まで含む4点で最終順位を付ける。

## 強弱の操作的定義

出走前の既存v3モデルの単独1着周辺確率を相対強度とする。ラインの相対強度は同ラインの各車の1着周辺確率の合計。3本中上位2本を比較上の強線、残る1本を比較上の弱線と呼ぶ。全選手の相対上位2人と、各二線内の線内上位選手同士も別に表示する。絶対的な「強強弱」認定や得点だけの区分ではない。境界同値時は強弱優勢を強制表示しない。

強弱の確率は複数ペアの合計ではなく最良の1ペアと比較する。全3ラインの強弱合計と強強1組を直接比較して組数差を有利さにしない。1・2着に3番手を含む診断も表示するが、3番手を基本4点へ追加しない。

## データと再現

- A級1・2班とS級を別学習。S級の学習元はF1。ガールズ・A3は対象外。7車の有効出走表、並び、通常決着を使用。事故・欠損等の除外と重複排除は既存cross_joint_v3/train.pyのloadと共通。
- 2023–2024年からSHA256(race_id)順で級別最大12,000R。A=12,000R、S=7,723R。2025年と2026年上半期22,166Rを時系列後続評価。2026年後半での独立確認は未実施。
- 41特徴で21通りの順序なし同時1・2着を学習。既存同時確率、相互作用なしモデル、単独強度とその積、ライン強度、第三ライン、位置、決まり手、両先頭の競合を入力。単独勝率の積だけを同時確率にしない。
- HistGradientBoostingClassifier: max_iter=80, max_leaf_nodes=7, min_samples_leaf=200, l2_regularization=5, learning_rate=.06, early_stopping=False, random_state=0。ハイパーパラメータは評価前に固定。入力に結果・払戻・オッズを使用しない。強制切替は探索的比較。
- `OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=2 python research/cross_coexistence_v1/analyze.py`。NumPy、SciPy、scikit-learnとNode.jsが必要。

共存学習後の21ペア確率をq、既存予測をpとすると、全210着順を `p_new(a,b,c)=p(a,b,c)*q({a,b})/p({a,b})` に更新する。ペア内の表裏比率と条件付き3着分布は保持する。全210着順の合計は1。個別に学習した21ペアの二値予測は全ペアで正規化してから使用する。
