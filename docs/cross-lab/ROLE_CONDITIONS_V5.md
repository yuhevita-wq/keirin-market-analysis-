# 先頭同士・番手同士・混合クロスの条件分析と組込み

対象は７車立て・３–２–２の35,131レース。2024年末まで19,060レースから学習し、2025年前半・後半、2026年前半を後続検証、2026年後半の収集済み部分を追加監査とした。2026年の通年評価ではない。

クロスは３連単４点。最初の依頼の３連複人気順位とは別の対象であり、この報告の配当・回収率は３連単である。２ラインの先頭同士、先頭と番手、番手同士に加え、３番手が１・２着に来る形も残した。１・２着が異線で、３着まで同じ２ライン内から出た場合を「２ライン内クロス」とした。

## 分かったこと

**役割の発生条件は読めるが、その比率で既存モデルを置き換えるだけでは、取り逃しも回収も安定して改善しない。** 今回は役割条件の比較表示と候補欠落の修正を組み込む。自動的に買い目を変更する補正は採用しない。

Ａ・Ｂは強い順ではなく、長いラインをＡ、同じ長さなら先頭の車番が小さいラインをＡとした。以下の境界は2024年末までのデータだけで学習した決定木の値であり、因果的な転換点ではない。

|Ａ級１・２班の条件|2025年前半|2025年後半|2026年前半|
|---|---:|---:|---:|
|Ａ先頭－番手 > 4.67、Ｂ先頭－番手 > −0.56：先頭×先頭|68.4%（52/76）|53.2%（42/79）|66.7%（50/75）|
|Ａ先頭－番手 ≤ 0.38、Ｂ先頭－番手 ≤ −0.56：番手×番手|28.8%（49/170）|33.2%（61/184）|26.5%（41/155）|
|Ａ先頭－番手 ≤ −5.34、Ｂ先頭－番手 > −0.56：Ａ番手×Ｂ先頭|48.4%（31/64）|49.2%（32/65）|62.3%（38/61）|

分母はその条件の２ライン内クロスだけ。全レースの的中率ではない。各条件の全該当組数、クロス数、５分類の発生数、回収率はanalysis.jsonに全級・全期間を収録。uncertainty_and_strata.jsonには３×２／２×２を分けた内訳と開催単位の再標本化区間も収録。Ｓ級でもライン内得点差による役割変化を確認した。Ｂ回数・逃げ・捲り・差し・マーク・相手ライン等22変数を候補にしたが、この小さい木では得点差と３連対率が主に残った。他の変数が無関係だという証明ではない。

## 配当に見合うか

条件ごとに「最も多い形」を選ぶだけでは不十分だった。たとえばＡ級条件９の先頭同士を４点で毎回買う回収率は、2025年前半134.3%、後半109.5%、2026年前半125.0%だった一方、2026年後半の収集済み部分では62.4%まで下がった。この条件を後付けで収益ルールに採用しない。

現行の同時入着モデルをそのまま使う対照と、今回の条件付き役割比率に補正するモデルを同じレースで比較した。先に選んだ２ラインを固定し、買うのはどちらも４点。下表は候補を全40型にした対照に対する補正の比較。

|A級1・2班・2025H1|2,559|39.5%|39.1%|68.1%|79.8%|
|A級1・2班・2025H2|2,592|41.3%|37.9%|82.9%|84.8%|
|A級1・2班・2026H1|2,407|40.3%|38.4%|63.7%|71.7%|

捕捉率の分母は対照が発走前に選んだ２ラインで実際にクロスが出たレース。回収率の分母は全評価レース×400円。候補の列挙で買い点数を増やしていない。補正は２ラインの事象全体の確率を保存し、役割配分だけを変更する。Ａ級では捕捉率の悪化があり、Ｓ級でも収益優位の証明に届かない。評価対象はＡ級１・２班とＳ級の13,144Ｒ、入力不備162Ｒを除外。Ａ級チャレンジ2,765Ｒは現行同時入着モデルの対象外のため、この直接比較に混ぜなかった。役割条件の学習・検証には含めた。

## システムへ組み込む内容

1. 先頭・番手だけの候補制限を撤去。３×２は18型、２×２は４型、３–２–２全体で40型。各型４点。１・２着の両方の順序と、残る３車から選ぶ２車を列挙する。
2. 全３組について、その出走表に該当する学習条件、先頭×先頭／両方向の混合／番手×番手／３番手の条件付き比率を表示する。
3. 同じ条件の各後続期間の母数・役割発生率・基本４点の回収率を展開表示する。推定比率と実現回収率を同じ意味にしない。
4. 答案保存に該当条件・学習終了日・母数・検証結果を含める。取り逃しをライン選択・頭の役割・３着・候補欠落に分けて追跡する。
5. 役割補正は研究用関数に残し、公開画面の予測や主採用に接続しない。発走後の結果・現在オッズは条件推定に使わない。

## 検証と限界

62件のテストが通過。PythonとJavaScriptの条件特徴・確率の一致、全210着順の候補網羅、40型すべて４点、確率の総和と２ライン事象の保存、画面表示と答案保存、既存固定答案の維持を確認した。

母集団はこの保存済みデータで確認できた３–２–２の全件であり、日本の全開催を網羅したという意味ではない。３連単の通常一意払戻を持つレースに限り、同着等は元の集計段階で除外している。同じレースから３つのライン組を作るため105,393組は独立105,393レースではない。学習対象の２ライン内クロスは6,039件、内訳Ａ級１・２班3,433、チャレンジ949、Ｓ級1,657。残りのレースも無条件の発生率・回収率の分母に残した。

検証期間は過去の研究でも参照した履歴であり、完全に未観測の将来実証ではない。役割分類は発走前情報との関連を捉えるもので、レース映像上の仕掛けや競りの因果を確認したものではない。条件を細かくしすぎると真のクロス件数が減るため、級ごと最大６葉・最少150クロスで固定した。回収率は高配当少数に左右され、開催単位の95%区間も多重比較を調整していない。クロス取り逃しをゼロ近くにした、または利益が出るシステムが完成した、とは結論しない。

グラフ・集計・再現用入力は別添の分析一式を参照。

画面の後続実績は該当葉に加えて３×２／２×２を分けて表示する。推定条件付き比率の学習は両構成を含み、表示する学習母数は全体と今回構成を併記する。
