このv37で使っているアルゴリズム

参加判定・1着段 v21

  • v21を採用し、このv37でも固定。
  • 1着候補は最大2人。
  • 対象率の基準は25%。直近4週間のスコア分位点を使用。
  • v31・v37の学習で1着コアは変更していない。

2着段 v31 Top2 Membership

  • v26の「順序を持たないTop2ペア」事後確率を使用。
  • 1着/2着への向き付けは行わない。
  • 各選手の所属質量 = その選手を含む全ペアの確率合計。
  • 所属質量上位2人を基本候補にする。
  • 3位が0.30以上、かつ2位の65%以上なら3人目を追加。最大3人。

Top2ペアモデル設定

  • variant: blind_d2a
  • depth 2 / leaf 18 / L2 1.5
  • learning rate 0.045 / 190 iterations
  • random_state 26
  • オッズ・人気は不使用。

3着段 v37

  • v31の全21個のTop2組を残し、各組に対する残り5人の3着確率を学習。
  • 21分岐をv31組確率で周辺化し、3着確率を生成。
  • 盤面整合性は候補除外に使わず、gamma=0.25の弱い再重み付けだけを適用。
  • 上位2人を基本候補とし、3位/2位確率比が0.70以上なら3人目を追加。4人置きなし。
