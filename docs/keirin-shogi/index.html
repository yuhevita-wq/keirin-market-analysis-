競輪将棋 駒置きアルゴリズム v0

オッズは使わず、出走表由来の5特徴から1着・2着・3着を別評価します。 まずは透明なルールベース。ここから実測で重みを壊して育てます。

手動駒:
手動配置も可能。下の出走表入力から自動配置できます。

出走表入力

車番 B数 勝率 % ライン長 番手差し評価 0-100 別線能力 0-100
1着は1〜2人、2着は2〜3人、3着は3〜4人。境界のスコア差が15以上なら候補を1人削ります。

アルゴリズム可視化

暫定重み
1着：B数 30% / 勝率 35% / ライン長 15% / 番手差し 5% / 別線能力 15%
2着：B数 10% / 勝率 20% / ライン長 20% / 番手差し 30% / 別線能力 20%
3着：B数 5% / 勝率 10% / ライン長 20% / 番手差し 20% / 別線能力 45%
各特徴は同一レース内で0〜100に正規化してから加重します。これは初期仮説であり、最終ルールではありません。
