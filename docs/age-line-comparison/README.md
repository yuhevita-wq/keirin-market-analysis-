# 年齢とライン構成別のワイド比較

`index.html` をダウンロードしてブラウザーで開くと利用できます。集計データはHTMLに内蔵しているため、データ取得サーバーやログインは不要です。

## 切り替えられる項目

- 年齢の対象：先頭・番手・3番手
- ラインの選び方：全ライン、B数順位、先頭得点順位、先頭の年齢順位
- レース全体の並びと対象期間
- 回収率・的中率・的中時平均払戻・車券数

表は2車ラインの先頭―番手、3車ラインの先頭―番手・先頭―3番手・番手―3番手を比較します。

## データ

- A1/A2・7車立て
- 2023〜2025年、2026年1〜8月、2026年9月1日〜10月2日
- 元の分析対象：42,623レース、19〜62歳
- 各点100円。全ライン表示では同じレースの複数ラインを含み、車券数とレース数は異なります。
- 元データ：本リポジトリの `data/a_class_12`
- 集計時の固定コミット：`ca54c40b40fc3451a8ca8fda05029fda0b2dde43`

年齢や並びが不完全なレース、ワイド払戻が取得できないレースなどは除外しています。値は保存時点の集計で、自動更新ではありません。

## ファイル

- `index.html`：スタイルと動作を含む単独閲覧用の保存版
- `fragment.html`：会話内で表示したツールの編集用ソース。単独利用には `index.html` を使ってください。

回収率が100％を超えるセルだけで購入ルールを決めず、車券数と期間別の成績も確認してください。
