# 競輪 Prediction Engine v1 契約

## 最終目的

未来のF1・S級・7車立てで、事前情報だけから着順分布を予測し、**予測・レース選択・買い目・資金評価を分離したうえで長期収支を検証する**。

「過去データで一番ROIが高かった条件」を探すことは目的にしない。未来へ持ち出しても壊れにくい構造だけを残す。

## データの時系列役割

- 2024Q1-Q2: 予測モデル学習
- 2024Q3: TicketPolicy選択
- 2024Q4: 選択済み1ルールの不可逆検証ゲート
- 2025H1: Q4合格時のみ破壊試験
- 2025H2: H1までの履歴を半期境界で追加して破壊試験
- 2026H1: 封印最終検証

### 禁止

- Q4を見てQ3のルールを変更する
- Q4で別のTicketPolicyを選ぶ
- Q4不合格なのに2025を開く
- 2025を見て2025用の閾値へ変更する
- 最終仕様固定前に2026H1結果・払戻を読む

## 事前入力として許可

発走前に存在する情報のみ。

- 開催日
- 競輪場
- レース番号
- レース種別
- 車番
- 選手識別情報（履歴結合専用）
- 年齢
- 期別
- 級班
- 脚質
- ギヤ
- 競走得点
- S/B
- 逃/捲/差/マ
- 1着/2着/3着/着外回数
- 勝率/2連対率/3連対率
- 楽天Kドリームス並び予想
- line_id / line_position / line_size
- 対象期間より前だけから計算した過去対戦・過去連係情報

## 事前入力として禁止

- `results.csv`
- `payouts.csv`
- `trifecta_final_odds.csv`
- `trio_final_odds.csv`
- 対象レース以後の結果から作られた特徴量
- 結果、払戻、確定オッズを示す派生列

確定オッズはT-10の実戦スナップショットではないため、v1の予測・レース選択・買い目決定には使用しない。

## モデル

### Statistical / Pairwise

7車の21ペアについて `AがBより先着する確率` を予測する。

相対得点、S/B、決まり手、ライン位置、ライン強度、レース番号、競輪場、レース種別、ライン形、脚質、級班などを使用する。

### Relationship

対象時点より前の履歴だけで

- 対戦数
- 先着率
- 同一ライン連係数
- 同一ラインで両者3着内になった率

を保持する。少数標本は縮小推定する。

### Similarity

選手名ではなく、ライン先頭能力とライン内位置から匿名構造ロールへ変換して近似レースを検索する。

同一レース種別、同一ライン数を優先し、標本不足時だけ緩める。

## 3連単確率

Pairwiseから得た7人の潜在強度をPlackett-Luceへ変換し、必ず7P3=210通りすべてを確率化する。

StatisticalとSimilarityを統合した後も、210通りの確率合計を1へ正規化する。

## TicketPolicy

確定オッズを読まない。

使用可能なのは

- 3連単確率分布のエントロピー
- 上位点への予測確率集中度
- StatisticalとSimilarityの不一致度
- 累積予測確率
- 最大点数

のみ。

Q3で比較できる候補グリッドは事前固定する。Q4開封後に候補を増やしてはいけない。

## 2024Q4ゲート

Q3で1つに固定したTicketPolicyだけをQ4へ適用する。

合格条件:

1. 購入60レース以上
2. Q4全体ROI >= 1.00
3. `月15レース以上購入 && 月ROI >= 0.85` を2か月以上

不合格ならv1はそこで終了し、2025は開かない。

## 2025破壊試験

Q4合格証明が必須。

- Statisticalの係数を変更しない
- TicketPolicyを変更しない
- H1を全部予測してから結果を使用する
- H1終了時にだけRelationship/Similarity履歴へH1を追加する
- H2を予測する
- 途中で閾値を変えない

## 2026H1封印

`DatasetCatalog`でsealed validationとして扱う。

`load_labels()` / `load_payouts()` は明示解除なしでは例外を出す。v1 CLIには2026開封コマンドを実装しない。

## 評価

ROI単独では判定しない。

最低限記録するもの:

- 評価レース数
- 購入レース数 / 購入率
- 的中率
- 投資額
- 払戻
- 収支
- ROI
- 平均点数
- 最大ドローダウン
- 最大連敗
- 月別成績
- 半期別成績
- モデル不一致度
- 予測分布集中度

## 情報漏洩防止

コード側で結果・払戻・確定オッズを示す特徴量を拒否する。

2025破壊試験はQ4ゲート合格フラグがないと関数レベルでも実行できない。単独CLIも、Q4合格レポートを要求する。

検証結果を見た後でルールを差し替えた場合、その時点で別バージョンとして扱い、既に見た期間を「完全未知検証」と呼ばない。
