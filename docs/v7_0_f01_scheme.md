# v7.0-F01 市場階層フォーメーション

## 目的

フォーメーションの人数・形を先に決めない。
3連単市場が各着順に作っている支持の階層構造から、1着・2着・3着の候補集合そのものを機械的に生成する。

## 使用データ

- 3連複35通り完全オッズ
- 3連単210通り完全オッズ
- 楽天Kドリームス並び予想

選手能力、得点、脚質、展開予想、結果、払戻は判定に使用しない。

## 入口

入口はv6.1のフォーメーション生成前の条件だけを継承する。

1. 3連複支持から各車Sを計算する。
2. 各ラインのLSを計算し、上位2ラインをA/Bとする。
3. ライン内隣接PS上位2組がA/Bから1組ずつであること。
4. 3連単1着支持H1上位2車がA/Bから1車ずつであること。
5. H1上位2車が各ラインの先頭または番手であること。
6. H1首位 < 2 × H1次位であること。

旧v6のM_pre条件、PruneDamage条件、AH/BH固定フォーメーションは継承しない。

## 各着順の市場支持

3連単210通りを逆オッズで正規化する。

q(t) = (1 / odds_t) / Σ(1 / odds)

各車iについて、

- H1(i) = iが1着の全qの合計
- H2(i) = iが2着の全qの合計
- H3(i) = iが3着の全qの合計

を計算する。

## 市場上位クラスター

H1、H2、H3をそれぞれ支持率降順に並べる。

隣接順位ごとに

support(r) / support(r+1)

を計算し、最も大きく支持が落ちる地点を、その着順の市場階層の境界とする。

したがって候補人数は固定しない。

例：

- 1着市場が1車だけ突出していれば1車
- 1〜2位が塊で3位から落ちれば2車
- 1〜4位まで近く5位から落ちれば4車

となる。

全車が完全同率なら境界がないため全車を残す。
最大落差が同率なら、より後ろの境界を採用して不必要に狭めない。

## 入れ子型フォーメーション

各着順から得た生の上位クラスターをR1/R2/R3とする。

- F1 = R1
- F2 = F1 ∪ R2
- F3 = F2 ∪ R3

必ず

F1 ⊆ F2 ⊆ F3

となる。

買い目表記は常に

F1 - F2 - F3

の1本で表現する。

例として市場がそう判断した場合のみ、

- 1 - 12 - 1234
- 12 - 123 - 12345
- 123 - 1234 - 123456

などになる。これらの人数・形を事前には指定しない。

## 買い目

F1 × F2 × F3 の直積から、同一車が複数着に入る無効順列だけを除外する。

残る全順列を各100円購入する。

## 廃止事項

- odds > N の価格カット：廃止
- 価格反復カット：廃止
- PruneDamage購入条件：廃止
- 1着人数固定：なし
- 2着人数固定：なし
- 3着人数固定：なし
- AH/BHごとに2着候補が変わる条件分岐フォーメーション：廃止
- ChatGPTの主観補完：なし

## 再現性

入力市場データと並びが同一なら、境界・F1/F2/F3・買い目・点数は必ず同一になる。
