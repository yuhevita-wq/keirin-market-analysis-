# 3-2-2構成・3連複期待値計算式（固定仕様 v1）

- 固定日: 2026-10-12
- 状態: **数式・演算順序は固定**／**得点補正係数は未推定・未検証**
- 変更規則: このファイルは v1 の記録として維持する。式・前提を変更する場合は v2 の別ファイルにし、何をなぜ変えたかを明記する。過去に試算した結果を見て v1 の定義を遡及変更しない。
- 対象車券: **3連複（着順不問）**
- 分析母集団: 全国 **S級予選、7車、事前の予想並びが3-2-2（3車ライン1本、2車ライン2本）**。別級班・別レース区分・9車戦へそのまま外挿しない。
- 目的: ライン構成・ライン内の役割から得た事前確率を、個々の選手の競走得点情報で補正して **35通り全ての確率**を出し、実際の3連複オッズで期待値を比較する。

## 0. 前提・定義（既存の固定データを継承）

- レース前に公表された各選手の競走得点 `score_i`、予想ライン `line_id`、ライン内位置 `line_position` だけを予測入力とする。結果・払戻・最終確定オッズを予測特徴として混入させない。
- 各ラインを **先頭と番手の得点の合計**で順位付け: `line_score(l) = score(l,1) + score(l,2)`。高い順に `H`（強）、`M`（中）、`L`（弱）。
- その得点合計が同値のラインがあるレースは、既存 v1/v2 の母集団に合わせて除外。勝手に別基準で優劣を決めない。
- 3車ラインの所属により、強・中・弱の車数 `s` は `3-2-2`, `2-3-2`, `2-2-3` のいずれか。**3車ラインを必ず H にしない**。
- `T` は7選手から異なる3人を選んだ順不同の3連複1点。`Ω_s` は該当レースの全35点。
- `m(T)` はその3人を H・M・L から何人ずつ選んだか（例 `2-1-0`）。
- `slot(T)` は H1、H2、H3、M1…といったライン順位と予想位置の3人組。

固定済み根拠:
- `data/probabilities/trio_line_composition_s_yosen_2023_2025_v1.json`
- `data/probabilities/trio_line_parts_s_yosen_2023_2025_v2.json`
- 参照検証: `data/probabilities/trio_line_parts_v2_2026_h1_validation.json`

v1/v2 の学習対象は 2023–2025 年の **3,015レース**。2026年上半期 **495レース** は後続期間の記述的比較に用いる（完全な盲検性・収益性の検証済みという意味ではない）。

## 1. 第1層：ライン構成（確定済み）

```text
P_line(m | s) = count(m, s) / count(s)
```

これは強・中・弱から何人入着するかの **同時の構成確率**。各ラインの独立な入着率の積ではない。

## 2. 第2層：ラインパーツ・35点のベース確率（確定済み）

```text
P_parts(T | m, s) = count(T, s) / count(m, s)  [m(T) = m]
P_base(T | s)     = P_line(m(T) | s) * P_parts(T | m(T), s)
                  = count(T, s) / count(s)
```

実装では既存 v2 の `by_line_size_shape[s].each_of_35_exact_trio_slot_tickets` にある **35点それぞれの実測確率**を `P_base` として取得してよい。

**二重計上禁止:** 既存の35点確率 `P_base` に、再びライン構成確率や「先頭先頭番手」等の集計確率を掛けてはいけない。それらはベース確率の内訳である。

**ゼロ観測への注意:** `count(T,s)=0` は不可能を意味しない。未観測票の平滑化（方式・強さ）は未確定であり、根拠なくゼロを確定確率として運用しない。

## 3. 第3層：選手得点による補正（数式枠組み固定・係数未確定）

レース `R` において候補となる事前情報:

```text
mean_score(R) = (sum of 7 prereace scores) / 7
delta_i       = score_i - mean_score(R)
gap_l         = score(l,1) - score(l,2)     [先頭 - 番手]
role_i        = (H/M/L, 1/2/3)
```

得点単独の生の3着内率だけではなく、`delta_i`・`gap_l`・`role_i` と相互作用を利用して、**3人組単位**の補正値 `f_theta(T, R)` を学習する。指数変換で正の重みを作る:

```text
w_theta(T, R) = exp(f_theta(T, R))

P_final(T | R) = [P_base(T | s) * w_theta(T, R)]
               / [SUM_{U in Ω_s} P_base(U | s) * w_theta(U, R)]
```

**固定する条件:**
1. 対象35点の `P_final` を **必ず合計100%** に正規化する。
2. 補正が中立（全 `w_theta=1`）なら `P_final=P_base`。
3. 個々の選手の3着内率を3人分掛け算して3連複確率にしない。同一レースの着内は非独立である。
4. `f_theta` の具体的な関数形・係数・平滑化・正則化は **このv1では決めていない**。後付けの適当な係数で代用しない。
5. スコアの根拠として結果判明後の特徴やオッズを流用しない。得点・並びの公表時点を揃える。
6. 補正後の確率の較正（calibration）と全35点の対数損失等を期間外データで確認する。

## 4. 3連複の期待値（固定）

```text
EV_ratio(T)        = P_final(T | R) * decimal_odds(T) - 1
Expected_profit(T) = stake_yen * EV_ratio(T)
```

- `decimal_odds` は元本込み払戻倍率（例: 12.0倍）。**別途控除率を二重に差し引かない**。
- EV は投資額に対する **期待純損益率**（例: `+0.20` は期待利益率20%）。
- オッズは確率推定には使わず、最後の期待値計算でのみ使う。買う・見送るための閾値、券種混合、金額配分は **本仕様では未固定**。
- オッズ不明の場合は `P_final` までで止め、期待値は欠測扱いとする。架空のオッズでEVを表示しない。

## 5. 実装・検証の合格条件

- [ ] 対象3ラインの車数が厳密に 3,2,2／7車／S級予選。得点同点除外を監査できる。
- [ ] H/M/Lの決定に当該レースの結果を使用していない。
- [ ] 35点が重複せず全列挙され、`SUM_T P_base(T|s)=1`、`SUM_T P_final(T|R)=1`。
- [ ] `w=1` で v2 の35点確率と一致する（丸め誤差のみ許容）。
- [ ] ライン構成・役割パターンの確率を二重に掛けていない。
- [ ] 得点補正は 2023–2025 年のデータで開発し、2026年上半期で後続期間の性能を比較する。ハイパーパラメータ選択に用いた期間は「未使用テスト」と称さない。
- [ ] 補正前後の較正、対数損失、Brier、期間別誤差を比較し、成績が改善しないなら得点補正を採用しない。
- [ ] 入着率・同時入着率の集計を、3連複1点の当選確率と混同しない。
- [ ] 各35点のEVは **実際に確認できた3連複オッズ**があるときのみ算出する。

## 未確定事項（固定済みと偽らない）

- `f_theta(T,R)` のモデル構造・学習済みパラメータ
- ベース頻度ゼロへの平滑化仕様
- 予測確率の外部時系列較正
- 本式によるプラス期待値・実運用利益の実証

**結論:** 固定したのは「ライン構成 → 役割35点のベース確率 → 得点情報で3人組を補正 → 35点を正規化 → 実オッズで EV = P×オッズ−1」の計算順序と制約であり、未検証の得点補正係数や期待利益は固定していない。
