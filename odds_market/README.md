# オッズ市場データ収集（他の予想システムから独立）

## 対象
- 全国すべての競輪場、級班・車数・ライン構成を事前に限定しない
- 全3連単組み合わせの**確定オッズ**を過去レースから収集する
- 7車なら210通り、9車なら504通り。欠けたレースは失敗記録を残し、全件扱いしない
- 人気上位50件、的中払戻、出走表に書かれた予想オッズで代用しない
- 一部レースが取得失敗しても他の成功レースと混ぜて「100%取得」と表明しない

## 情報源と注意
[楽天Kドリームス開催一覧](https://keirin.kdreams.jp/kaisai/)からレースページを発見。オッズ表のデータ形式は2024年の過去レースで確認したが、HTML取得・解析を実サイトに対して自動実行した検証はまだ完了していない。

**公開リポジトリにサイトの全オッズを無断コピーしないこと。** [サイト利用条件](https://keirin.kdreams.jp/info/sitepolicy/)が無断コピー・転載を禁じている。再利用・大量収集・公開保存について必要な利用許諾を確認すること。収集ワークフローは手動起動のみで、取得データをGit履歴に自動コミットしない。

## 実行
```bash
python -m pip install requests beautifulsoup4
python -m odds_market.test_collect_final
python odds_market/collect_final.py --start 2024-07-06 --end 2024-07-06 --out /path/to/private/odds
```
許諾・利用条件を確認した後、[GitHub Actions](https://github.com/yuhevita-wq/keirin-market-analysis-/actions/workflows/odds-market.yml) の **Run workflow** から開始日・終了日を指定できる。1回の実行は最長7日。失敗時もmanifestに理由が残る。Actions artifactは短期保管のため恒久データ倉庫として扱わない。

## 保存形式
`YYYY/YYYY-MM-DD.csv.gz`：完全取得できたレースの全買い目。各レコードは `race_id, first, second, third, odds` を中核として、発売票数、オッズ時刻、取得時刻、参照URLなどを持つ。

`YYYY/YYYY-MM-DD.manifest.json`：発見レース数、完全取得レース数、買い目件数、失敗詳細。

表示オッズ `9999.9` はサイト表示上限の可能性があるため、`display_cap=1` として別扱い。これを厳密な実オッズだとみなして確率推定しない。

## 15分前オッズと確定オッズの区別
過去ページで確認できたのは**確定オッズ**。15分前の市場価格を再現したわけではない。15分前オッズは今後、実際に締切前に観測してタイムスタンプ付きの別データセットとして保存する。確定オッズで検証した利益を、そのまま締切15分前に購入できた利益と混同しない。

このサブシステムはオッズのみの研究基盤であり、出走表の得点・戦法・ライン等から予測する別方式を自動導入しない。
