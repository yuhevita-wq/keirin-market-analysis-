# 小倉F1・S級初日：確率 × オッズによる期待値分析 v1

2026-10-11の会話で使った考え方、計算、数値を固定した再現可能な基準版。
ユーザーが採用したのは「起こる確率と価格を比較する作戦」。この確率モデルが真の確率を推定できたことや、利益を実証できたことを意味しない。
既存の競輪将棋・マークシート・参加判定の運用には接続していない。

## 固定する計算

確率は小数、オッズは払戻総額を含む倍率として扱う。

| 項目 | 式 | 例：的中確率10％、12倍、100円 |
|---|---|---|
| 期待回収率（倍率） | p × odds | 1.2 |
| 期待回収率（％） | p × odds × 100 | 120％ |
| 期待利益率 | p × odds − 1 | 20％ |
| 期待損益 | stake × (p × odds − 1) | ＋20円 |
| 収支分岐の的中確率 | 1 ÷ odds | 8.33％ |

表示オッズに通常の控除は反映済みなので、追加で75％などを掛けない。
３連単は７車の全210通り。３連複は全35通りで、対応する３連単６通りの確率を足す。
券種ごとに確率の総和は１。各券の数値は「その券だけを買う」期待値であり、複数点の合計回収率ではない。
複数点では金額加重して、期待払戻総額 ÷ 投資総額を計算する。

## 分析の進め方

1. 開催・日付・レース区分・７車・選手コメント・並びを確認する。予選と初特選を混同しない。
2. オッズを入れずに全選手を評価する。実力・近況・役割を１着、２着、３着へ直結させず、候補間の比較を残す。
3. 全210通りの確率を計算し、全35通りの３連複へ集計する。
4. 取得時刻付きのオッズと照合する。確率順と期待回収率順を別々に確認する。
5. 本線が全部残る形、１人だけ外れる形、構成員は同じで順序が変わる形を具体的な選手名・番号で比較する。
6. 表示する候補は確率・オッズ・期待回収率を同時に示す。低期待値だけを理由に「起こりうる結果」の説明から消さない。
7. 数値と選手評価が食い違ったら、その差を明示する。説明に合わせて確率を書き換えない。
8. 高期待値の根拠が位置取り・追走・切り替えなど未観測の要因に依存する場合、未検証として扱う。
9. 結果後は、的中／不的中だけでなく、候補欠落、構成員誤差、順序誤差、確率の校正、最終配当での回収を分けて検証する。

これは当日の作戦の記録。新しい点数上限、頭固定、穴必須、特定券種固定、連敗時の増額などは導入しない。

## 今回の確率モデル

- 元データのコミット：`1580d39f21aa24dfa3accd25c6b049b32b287913`。
- 小倉F1初日の照合結果226件のうち、７車・出走表が揃う199件をモデルに使用。予選168件、初特選31件。
- 特徴量：レース内相対得点、B回数、直近勝率・３連対率、番手／３番手以降／単騎、同ライン・隣接関係、初特選の一部相互作用。特徴量の順序と重みは `frozen_model.json` に保存。
- 全210通りの条件付き多項ロジット。L2正則化、ridge=1、確率を平滑化する温度=1.2。
- 2025年より前107件、2025年以降92件の検証でridgeを1・10・100から選択。同じ検証集合で温度も選んだ。独立した最終評価は未実施。
- オッズは確率推定に使わない。現在の詳細な位置取り、追走能力、コース、仕掛け時刻、直近各走の内容・欠場理由は特徴量に入っていない。
- 2023年Q1の結果や一部出走表など欠測がある。`training.json` は今回実際に使用した199件の入力・結果を保存したもので、全期間網羅を意味しない。
- 当日の確率は着順結果が出る前に計算済み。重みの保存は結果後だが、当日の結果で重みを再学習していない。

`p05`・`p95` は開催日単位で30回再標本化したモデルの５％・95％点。
小標本の変動を見る補助値であり、真の確率の保証範囲ではない。モデル構造の誤りは含まない。
手動の「確率を30％下げる」などは感度確認で、統計的な信頼区間ではない。

## 当日の失敗・限界も固定

- ８R、ユーザー報告の結果1-4-7。３連複147は推定5.7338％、18:24オッズ7.0倍、期待回収率約40.1％。３連単1-4-7は推定1.2993％、40.1倍、約52.1％。③⑦中心へ説明を狭め、④①の上位と⑦だけの残りを十分に分析しなかった。
- 11R、ユーザー報告の結果1-2-7。19:47の３連複127は推定10.85％、5.8倍、約62.9％。３連単1-2-7は推定約1.53％、27.0倍、約41.2％。全数値には存在したが最終表・比較から落とした。「②の３着限定は不適切」という評価と最終回答が不整合だった。
- 12Rの137はモデル推定2.85％。①③⑦の実力・近況との乖離を指摘した。同ラインの組を強く評価して異なる３ラインの混合を軽く見ている可能性は仮説で、原因検証済みではない。
- 番手・３番手の位置による有利さと、その選手の現在の能力を分ける必要がある。高期待値が⑥など特定の弱い選手へ集中する場合、その確率推定を検証する。
- 的中した券の事前期待値が低かったことだけでは、推定が誤りとも正しいとも判断できない。長期の未見レースで確率校正と回収率を評価する。

## 保存ファイルと再計算

| ファイル | 内容 |
|---|---|
| `model.py` | 入力検証、全着順の確率、期待値、CSV出力、固定仕様での再学習関数 |
| `frozen_model.json` | v1の重み、特徴量、温度、正則化、検証情報、実行環境 |
| `training.json` | 実際の199件の学習入力と結果 |
| `cards_20261011.json` | ７〜12Rのモデル入力 |
| `odds_20261011.json` | 各Rで最後に分析した時刻の全オッズ。最終オッズではない |
| `all_outcomes_20261011.csv` | ６R×245＝1470件。確率、オッズ、期待回収率、100円の期待損益、収支分岐、標本変動 |
| `snapshot_history.json` | 初回と更新後の全数値。オッズ更新後の期待損益も再計算済み |
| `verify.py` | 全組み合わせ、確率総和、３連複集計、期待値、重み再現の検証 |

```bash
  --cards experiments/kokura_f1_ev/v1/cards_20261011.json \
  --odds experiments/kokura_f1_ev/v1/odds_20261011.json \
  --out /tmp/kokura_ev_recomputed.csv
```
